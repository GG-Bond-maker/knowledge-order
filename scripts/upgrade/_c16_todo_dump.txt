### 为什么直接对比两组均值通常全错？
初入职场的分析师最容易犯的低级错误：直接用“处理组均值 - 未处理组均值”作为策略效果。
- 例子：某 App 上线了 VIP 会员付费服务。分析师发现：VIP 用户的次月留存率是 85%，非 VIP 用户仅为 40%。分析师兴奋汇报：“VIP 会员功能让留存率提升了整整 45 个百分点！”

#### 拆解均值差异的数学根源：
设 $D_i \in \{0, 1\}$ 表示是否购买 VIP，$Y_i(1)$ 表示购买 VIP 后的留存结果，$Y_i(0)$ 表示不购买 VIP 时的留存结果。
观测到的组间差异可精确分解为：
$$E[Y | D = 1] - E[Y | D = 0] = \underbrace{E[Y(1) - Y(0) | D = 1]}_{\text{处理组平均因果效应 (ATT)}} + \underbrace{\Big( E[Y(0) | D = 1] - E[Y(0) | D = 0] \Big)}_{\text{选择性偏差 (Selection Bias)}}$$

#### 选择性偏差剖析：
- $E[Y(0) | D = 1]$：那些自愿购买 VIP 的忠诚用户，**假使他们当初没有买 VIP**，他们的留存率本来就有 80%！
- $E[Y(0) | D = 0]$：普通非 VIP 用户的留存率只有 40%。
- 选择性偏差 $= 80\% - 40\% = 40\%$！
- 真实的会员增量（ATT）其实只有 $85\% - 80\% = 5\%$！原本微弱的 5% 增量，被高达 40% 的自选择偏差严重掩盖和粉饰。

### 混杂变量（Confounder）的定义
当一个变量 $Z$ 同时影响处理变量 $X$ 和结果变量 $Y$ 时，变量 $Z$ 称为 $X$ 与 $Y$ 的**混杂变量（Common Cause / Confounder）**。

```
       混杂变量 Z (如气温、用户财富、疾病严重度)
        ↙             ↘
处理变量 X             结果变量 Y
(冰淇淋销量 / 买会员)   (溺水人数 / 用户留存)
```

#### 混杂产生的虚假关联：
- 混杂变量 $Z$ 在 $X$ 和 $Y$ 之间搭建起了一条非因果的信息流通渠道（后门路径 Backdoor Path）。
- 即使 $X$ 对 $Y$ 的真实因果效应为 0，数据中 $X$ 与 $Y$ 也会呈现出强烈的统计相关性。
- **因果识别的本质任务**：通过合理的统计设计（如随机化）或观察性控制（如控制变量、匹配、固定效应），**彻底切断所有由混杂变量构成的后门路径！**

### 因果推断与传统统计的根本认知分工
因果推断研究必须严格划分为两个阶段：

#### 1. 因果识别阶段（Causal Identification）
- **核心问题**：“假定样本量无限大（掌握了全宇宙无偏的总体联合分布 $P$），我们能否从可观测的数据中唯一无歧义地解出因果干预效应（$\text{do}$ 算子）？”
- **产物**：将不可直接观测的反事实因果参数（如 $E[Y(1) - Y(0)]$），转化为仅由现实观测概率构成的等价数学表达式（识别公式）。
- **依据**：依赖理论假定（如不可混杂假定 Unconfoundedness、工具变量外生性、平行趋势假定）。**如果因果识别假定不成立，再大的样本量、再复杂的神经网络也只是非常精确地估计出错误答案！**

#### 2. 统计估计阶段（Statistical Estimation）
- **核心问题**：“在识别公式成立的前提下，面对手头有限且带随机噪声的有限样本，如何构建统计量进行无偏、有效、渐近正态的数值估计与置信区间推断？”
- **方法**：OLS、倾向得分匹配、G-computation、双重机器学习（Double ML）。

### 反事实是人类智慧与因果推断的终极基石
诺贝尔奖得主珀尔（Judea Pearl）提出因果关系三层阶梯（Ladder of Causation）：
1. **第一层：关联（Association）** —— 观察：“若看到 X，Y 的概率是多少？”（纯被动观察，现代深度学习与传统统计的边界）。
2. **第二层：干预（Intervention）** —— 行动：“如果我们主动执行 $\text{do}(X=x)$，Y 会变成什么？”（A/B 测试、政策干预）。
3. **第三层：反事实（Counterfactuals）** —— 想象与回顾：“若当初我没有给该用户发放 50 元大额红包，他今天还会下单购买吗？”（归因分析、法律责任判定、个性化精准补贴 Uplift Modeling）。

#### 商业增量（Uplift）四大客群划分：
针对任意运营干预策略，目标受众天然由四类人构成：
1. **铁杆忠诚型（Sure Things）**：不给券也会买，$Y(1)=1, Y(0)=1$。发券纯属浪费营销预算！
2. **沉睡绝望型（Lost Causes）**：给券也不会买，$Y(1)=0, Y(0)=0$。发券同样徒劳无功。
3. **易受影响型（Persuadables / 增量人群）**：不给券不买，给券才买，$Y(1)=1, Y(0)=0$。**唯一的净商业增量来源！**
4. **反作用叛逆型（Sleeping Dogs）**：不打扰他好好的，一旦发短信推送反感卸载，$Y(1)=0, Y(0)=1$。

**因果推断的商业终极价值**：通过反事实建模识别 Persuadables 人群，实现增量最大化与营销成本归零！

真实商业场景往往无法做完美的 A/B 测试（涉及伦理、竞对政策、全量功能发布或不可抗力）。因果推断发展出五大准实验（Quasi-Experiment）神技：

能否做随机化实验？

### 算例拆解：高阶会员留存的选择性偏差精确解构
某知识付费平台分析购买 99 元年度会员（$D$）对次年续费留存（$Y$）的影响。
- 观测数据：
  - 会员群体（$D=1$）：共 10,000 人，次年留存 7,000 人，观测留存率 $E[Y|D=1] = 70\%$。
  - 非会员群体（$D=0$）：共 90,000 人，次年留存 18,000 人，观测留存率 $E[Y|D=0] = 20\%$。
  - 粗暴的均值差异：$70\% - 20\% = 50\%$。

#### 严谨的反事实调研与潜在结果测定：
通过对两组用户在购买前的历史完课时长和学习活跃度进行高精度匹配调查，推断出会员群体若当初未买会员时的反事实留存率：
$$E[Y(0) | D=1] = 55\%$$
（因为自愿掏钱买会员的人本身就是求知欲极强的高粘性学霸，就算不买会员，留存率也高达 55%）。

#### 反事实因果与偏差分解：
1. **真实处理组平均因果效应（ATT）**：
   $$ATT = E[Y(1) - Y(0) | D=1] = E[Y(1)|D=1] - E[Y(0)|D=1] = 70\% - 55\% = 15\%$$
2. **选择性偏差（Selection Bias）**：
   $$\text{Bias} = E[Y(0)|D=1] - E[Y(0)|D=0] = 55\% - 20\% = 35\%$$
3. **验证等式**：
   $$\text{观测均值差} (50\%) = ATT (15\%) + \text{Selection Bias} (35\%)$$

### 科学史上最残酷的缺失数据问题
荷兰统计学家 Paul Holland 提出著名论断：
**因果推断的根本难题在于：对于任何一个具体的受试个体 $i$，我们在现实世界中永远只能观测到 $Y_i(1)$ 或 $Y_i(0)$ 中的某一个，绝不可能同时观测到两者！**

$$Y_i = D_i \cdot Y_i(1) + (1 - D_i) \cdot Y_i(0)$$
- 若个体接受处理（$D_i = 1$），则 $Y_i(1)$ 成为现实观测值，而 $Y_i(0)$ 沦为**反事实（Counterfactual）**，永远沉入历史的虚无；
- 若个体未受处理（$D_i = 0$），则 $Y_i(0)$ 成为现实，而 $Y_i(1)$ 成为反事实。

```
现实世界观测表：
用户 i    处理 Di    实际观测 Yi    潜在结果 Y(1)    潜在结果 Y(0)    真实个体效应 τi
张三       1          120           120 (可测)       ? (永远缺失!)    无法直接计算!
李四       0          140           ? (永远缺失!)    140 (可测)       无法直接计算!
```

**因果推断的本质破局**：既然无法在个体层面算出 $\tau_i$，统计学退而求其次，转向估计**人群总体的平均处理效应（Average Treatment Effects）**！

### 必须分清的三个宏观平均因果量
由于个体效应不可测，统计学定义了三大约束层面的平均因果量：

#### 1. 总体平均处理效应（Average Treatment Effect, ATE）
- **定义**：全社会或全量大盘中所有个体因果效应的无条件期望：
  $$ATE = E[Y(1) - Y(0)]$$
- **适用场景**：面向全员强制推广的普适性政策（如全民免费医疗体检、App 默认改版升级）。

#### 2. 处理组平均处理效应（Average Treatment Effect on the Treated, ATT）
- **定义**：仅在那些**实际接受了处理的受试人群**内部的平均因果效应：
  $$ATT = E[Y(1) - Y(0) | D = 1]$$
- **适用场景**：自愿参与类活动评估（如付费购买了 VIP 的会员群体的真实留存增量、报名参加职业培训班的失业工人增量）。

#### 3. 对照组平均处理效应（Average Treatment Effect on the Controls, ATC）
- **定义**：在那些**当前未接受处理的对照人群**内部，假使给他们施加处理能够产生的平均因果效应：
  $$ATC = E[Y(1) - Y(0) | D = 0]$$
- **适用场景**：业务拉新与破圈潜力测算（“如果我们把黑卡推销给目前不买黑卡的普通用户，预期增量是多少”）。

#### 三者代数关系：
总体 ATE 是 ATT 与 ATC 的加权平均（加权权重为处理组比例 $\pi = P(D=1)$）：
$$ATE = \pi \cdot ATT + (1 - \pi) \cdot ATC$$
当处理效应存在异质性（Heterogeneity）时，三者数值通常截然不同！

### 因果推断的第一前提公理：SUTVA
Rubin 提出，要使得潜在结果 $Y_i(d)$ 具有唯一定义，必须满足**稳定单元处理值假定（Stable Unit Treatment Value Assumption, SUTVA）**。它包含两个紧密相关的子假设：

#### 1. 无干扰 / 无溢出（No Interference）
- **内涵**：任意个体 $i$ 的潜在结果，**只取决于个体 $i$ 自身接受的处理状态，与任何其他个体的处理分配完全无关**！
- 数学表达：$Y_i(D_1, D_2, \dots, D_n) = Y_i(D_i)$。
- **违背场景**：
  - 传染病疫苗：他人接种疫苗产生了群体免疫屏障，直接降低了未接种者的感染风险（负溢出）；
  - 社交网络：好友获得了砍价红包，邀请对照组好友助力，对照组被间接处理；
  - 双边供需竞争：实验组司机优先派单抢走对照组司机的订单。

#### 2. 无隐藏处理版本（No Hidden Variations of Treatment）
- **内涵**：处理状态 $D_i = 1$ 的物理含义在所有个体之间是均一恒定的，不存在不同版本的暗度陈仓。
- **违背场景**：研究“做手术”对心脏病生存率的影响，但有的人由顶尖院士操刀（高标准版本），有的人由实习医生操刀（低版本），统一标为 $D=1$ 会导致潜在结果定义模糊失效。

### 连通现实与反事实的两座金桥

#### 1. 一致性假定（Consistency）
- **内涵**：个体实际观测到的结果 $Y_i$，严格等于其真实接受的处理状态所对应的潜在结果：
  $$\text{若 } D_i = d, \quad \text{则 } Y_i = Y_i(d)$$
  $$Y_i = D_i Y_i(1) + (1 - D_i) Y_i(0)$$
- 核心要求：干预操作本身不能附带额外的不受控副作用（如盲测中服下安慰剂的心理暗示效应）。

#### 2. 条件无混杂假定（Conditional Ignorability / CIA）
- **内涵**：在充分控制了可观测的协变量集合 $X$ 之后，处理分配 $D$ 与潜在结果 $Y(1), Y(0)$ 条件统计独立：
  $$(Y(1), Y(0)) \perp D \mid X$$
- 直觉：只要把年龄、收入、病史等背景变量 $X$ 全部固定锁死，在该细分客群内部，谁吃药谁没吃药就如同掷硬币一样纯属偶然，不再包含任何隐藏自选择动机！
- 威力：CIA 是回归调整、倾向得分匹配、G-computation 等所有观测性研究识别 ATE 的绝对命门。

### 共同支撑域（Common Support）的严苛红线
即使满足了无混杂假定，如果数据缺乏**重叠性（Positivity / Overlap）**，因果推断依然会轰然倒塌！

#### 正值性公理（Positivity Assumption）：
对于协变量空间中任意可能存在的特征组合 $x$（且 $P(X = x) > 0$），个体接受处理的条件概率必须严格介于 0 到 1 之间：
$$0 < P(D = 1 | X = x) < 1$$

#### 违背重叠性的灾难场景：
- 例子：研究某重症抢救手段对死亡率的影响。在现实医院中，所有 80 岁以上且处于休克的患者 100% 会被送去急救（$P(D=1|X) = 1$），从来没有任何一个此类患者被留在普通病房作为对照（$P(D=0|X) = 0$）。
- 致命后果：在“80岁且休克”这一细分特征人群中，**对照组的样本数严格为零**！
- 统计崩溃：倾向得分分母为 0 导致数值发散。任何模型试图估计该人群的因果效应，都纯属在没有任何现实数据支持的前提下进行极度危险的无底线外推（Extrapolation）！

#### 工业级治理措施：
在因果推断实操中，必须绘制处理组与对照组的倾向得分重叠直方图，坚决剔除（Trimming）倾向得分极度接近 0（如 $< 0.05$）或极度接近 1（如 $> 0.95$）的不可比极端个体。

### 算例拆解：小型总体的潜在结果全景透视
假设某微型公司共有 6 位员工，公司考虑推行“远程弹性办公（$D=1$）”。上帝视角下的完整潜在结果矩阵如下（单位：月度产出点数）：

| 员工 | $D_i$ | $Y_i(0)$ 基线 | $Y_i(1)$ 弹性 | $\tau_i = Y_i(1)-Y_i(0)$ | 实际观测 $Y_i$ |
| :--- | :--- | :--- | :--- | :--- | :--- |
| A | 1 | 80 | 95 | +15 | 95 (已测) |
| B | 1 | 70 | 90 | +20 | 90 (已测) |
| C | 1 | 60 | 70 | +10 | 70 (已测) |
| D | 0 | 90 | 92 | +2 | 90 (已测) |
| E | 0 | 85 | 86 | +1 | 85 (已测) |
| F | 0 | 75 | 74 | -1 | 75 (已测) |

#### 精确指标计算：
1. **真实个体效应**：$\tau = [+15, +20, +10, +2, +1, -1]$。
2. **总体平均因果效应（ATE）**：
   $$ATE = \frac{15 + 20 + 10 + 2 + 1 - 1}{6} = \frac{47}{6} \approx +7.83$$
3. **处理组平均因果效应（ATT）**（员工 A, B, C）：
   $$ATT = \frac{15 + 20 + 10}{3} = \frac{45}{3} = +15.0$$
4. **对照组平均因果效应（ATC）**（员工 D, E, F）：
   $$ATC = \frac{2 + 1 - 1}{3} = \frac{2}{3} \approx +0.67$$
5. **验证凸组合**：处理比例 $\pi = 3/6 = 0.5$。
   $$0.5 \times 15.0 + 0.5 \times 0.67 = 7.5 + 0.335 = 7.835 \approx ATE$$（精准吻合！）
6. **观测均值差 vs 真实因果**：
   - 处理组观测均值 $= (95 + 90 + 70)/3 = 85.0$
   - 对照组观测均值 $= (90 + 85 + 75)/3 = 83.33$
   - 观测均值差 $= 85.0 - 83.33 = +1.67$
   - 剖析：真实 ATT 高达 +15.0，但观测均值差只有 +1.67！因为主动申请远程办公的 A、B、C 员工原本的基线能力（平均 70 分）远低于坐班组 D、E、F 的基线能力（平均 83.33 分），选择性偏差为 $70 - 83.33 = -13.33$ 分，将巨大的增量生生掩盖！

### 图论赋能因果推断：Judea Pearl 的因果革命
图灵奖得主 Judea Pearl 提出了**因果有向无环图（Causal Directed Acyclic Graph, DAG）**，将晦涩的反事实假定转化为直观优雅的几何路径代数！

#### 因果 DAG 的基本语法：
1. **节点（Nodes / Vertices）**：代表变量（包括可测变量 $X, Y, Z$ 与不可测潜在变量 $U$）。
2. **有向箭头（Directed Edges, $A \to B$）**：表示 $A$ 是 $B$ 的**直接原因（Direct Cause）**。
3. **无环（Acyclic）**：因果箭头不能形成死循环闭环（原因必然发生在结果之前，时间单向流逝）。
4. **父节点与子节点**：若 $A \to B$，则 $A$ 是 $B$ 的父节点（Parent），$B$ 是 $A$ 的子节点（Child）；延伸路径上的所有节点分别称为祖先（Ancestors）与后代（Descendants）。

#### 因果马尔可夫假定（Causal Markov Condition）：
在给定某个变量的所有直接原因（父节点 $\text{Parents}(V)$）的条件下，该变量**与其所有非后代节点（Non-descendants）条件独立**！
$$P(V_1, V_2, \dots, V_k) = \prod_{j=1}^k P(V_j \mid \text{Parents}(V_j))$$
这一公理赋予了因果图与联合概率分布之间的无缝映射能力。

### 任意复杂因果图的三个原子积木
所有宏观因果网络，本质上都由以下三种基本三节点连接结构复合而成：

#### 1. 链条结构（Chains / 中介链）：$A \to B \to C$
- **现实范式**：教育（$A$） $\to$ 认知技能（$B$） $\to$ 薪资收入（$C$）。
- **连通性规则**：
  - 默认情况下（未控制 $B$）：信息自由流动，$A$ 与 $C$ **相关（Dependent）**。
  - **一旦控制 / 条件化 $B$（Conditioning on $B$）**：路径被**阻断（Blocked）**！$A$ 与 $C$ 变为**条件独立（$A \perp C \mid B$）**。

#### 2. 分叉结构（Forks / 共同原因）：$A \leftarrow B \to C$
- **现实范式**：气温（$B$）同时导致冰淇淋热卖（$A$）和溺水增加（$C$）。
- **连通性规则**：
  - 默认情况下：由于共同原因 $B$ 的存在，$A$ 与 $C$ 呈现出虚假的统计**相关（Dependent）**。
  - **一旦控制 / 条件化 $B$**：后门信息管道被切断，路径被**阻断（Blocked）**！$A$ 与 $C$ 恢复**条件独立（$A \perp C \mid B$）**。

#### 3. 碰撞体结构（Colliders / 共同结果）：$A \to B \leftarrow C$
- **现实范式**：数学天赋（$A$）与体育特长（$C$）共同影响名校录取（$B$）。
- **连通性规则（极其反直觉！）**：
  - **默认情况下（未控制 $B$）**：路径是**天然阻断的（Blocked）**！$A$ 与 $C$ 相互**独立（$A \perp C$）**！
  - **一旦控制 / 条件化碰撞体 $B$（或控制了 $B$ 的任何后代节点）**：**原本阻断的路径会被强行激活打通（Unblocked）！**导致原本毫无联系的 $A$ 与 $C$ 产生虚假的条件相关（伯克森悖论）！

### 如何在复杂因果图中一眼看穿独立性？
Pearl 提出的 **d-分离准则（Directional Separation）** 是一套严密的图论判定法则。

#### 路径阻断的充要判定准则：
一条连接变量 $X$ 和 $Y$ 的路径，在给定调节控制变量集合 $Z$ 的条件下是**被阻断（Blocked / d-separated）**的，当且仅当满足以下两条规则之一：
1. 路径上包含至少一个**链条节点（$A \to B \to C$）**或**分叉节点（$A \leftarrow B \to C$）**，且该节点 $B \in Z$（即被控制了）；
2. 路径上包含至少一个**碰撞体节点（$A \to B \leftarrow C$）**，且该碰撞体节点 $B \notin Z$，并且其所有后代节点也都不在集合 $Z$ 中（即碰撞体未被控制）。

#### d-分离与概率独立的等价定理：
若在因果 DAG 中，在给定节点集合 $Z$ 的条件下，$X$ 与 $Y$ 之间的所有可能路径全都被阻断，则称 $X$ 与 $Y$ 被 $Z$ **d-分离（d-separated）**！
$$X \text{ 与 } Y \text{ 在 DAG 中被 } Z \text{ d-分离} \iff X \perp Y \mid Z \text{ (在概率分布中严格条件独立)}$$

### 当后门混杂完全不可测时怎么办？
假设研究“吸烟（$X$）”对“肺癌（$Y$）”的因果效应。
烟草公司狡辩称存在一种未测基因 $U$：该基因既让人烟瘾极大，又让人极易患肺癌（$X \leftarrow U \to Y$）。由于人类基因极其复杂且无法全测，$U$ 是不可观测的混杂变量，后门路径无法直接阻断！

```
     不可测混杂 U (体质/基因)
       ↙             ↘
吸烟 X ──> 肺部焦油沉积 M ──> 肺癌 Y
```

#### 前门准则（Frontdoor Criterion）神技：
如果存在一个**中介变量 $M$（如肺部焦油沉积）**满足以下三个拓扑条件：
1. $M$ 完全截断了 $X$ 对 $Y$ 的所有直接和间接因果路径（所有因果效应都必须通过 $M$ 传递）；
2. $X$ 到 $M$ 之间不存在任何后门路径（即没有混杂因素同时影响吸烟和焦油）；
3. $M$ 到 $Y$ 之间的所有后门路径均被 $X$ 阻断（$M \leftarrow X \leftarrow U \to Y$ 在控制了 $X$ 之后被阻断）。

#### 前门调整识别公式：
$$P(Y \mid \text{do}(X=x)) = \sum_m P(M=m \mid X=x) \sum_{x'} P(Y \mid X=x', M=m) P(X=x')$$
**奇迹发生**：即使混杂变量 $U$ 彻底不可测，前门准则依然能够利用可观测的焦油中介变量，100% 纯净识别出吸烟对肺癌的因果效应！

### 致命误区：把能收集到的所有变量全放进回归
许多传统分析师有一句口头禅：“控制变量越多越好，反正多控制一个又不花钱”。**这是极其荒谬且危险的！控制了错误的变量，会凭空把原本无偏的模型彻底搞报废！**

#### 三大约束绝不能碰的“坏控制变量（Bad Controls）”：
1. **中介变量（Mediators）**：
   - 例子：研究大学文凭（$X$）对薪资（$Y$）的因果效应，若控制了“是否成为企业管理层（$M$）”。
   - 后果：上大学正是通过提升成为高管的概率来赚取高薪的！控制了中介变量，会扼杀掉主干因果路径，导致大学文凭的效应被严重人为低估（过度控制偏误 Over-controlling Bias）。
2. **结果的后代 / 代理变量（Proxies for Outcome）**：
   - 控制了干预发生之后的结果表征，直接吸收掉结果方差。
3. **碰撞体（Colliders）与 M-偏误（M-Bias）**：
   - 观察经典 M 型拓扑图：
     ```
     U1 ────> C <──── U2
      │                │
      ▼                ▼
     处理 X           结果 Y
     ```
   - 拓扑分析：$U_1$ 和 $U_2$ 是不可测变量。在原始图中，路径 $X \leftarrow U_1 \to C \leftarrow U_2 \to Y$ 在节点 $C$ 处是碰撞体（$U_1 \to C \leftarrow U_2$），**默认是完全阻断的！** $X$ 与 $Y$ 之间原本干干净净，没有任何后门污染。
   - 灾难操作：分析师自作聪明在回归里控制了变量 $C$！控制碰撞体 $C$ 瞬间**激活打通了该路径**，人为制造出了原本不存在的严重混杂偏差（M-bias）！

某电商平台研究促销降价（$X$）对用户次月复购频次（$Y$）的因果效应。
经过与业务、产研团队深度对齐，梳理出如下业务因果网络：
- 节点：$X$（促销降价）、$Y$（复购频次）、$A$（用户历史消费水平 / 购买力）、$B$（用户价格敏感度 / 羊毛偏好）、$C$（用户领券后进店时长）、$S$（双十一大促平台活动曝光，同时受 $A$ 和 $B$ 影响的大促人群打标）。

```
因果拓扑图：
       A (购买力) ──> S (大促打标) <── B (价格敏感度)
      ↙   ↘                             ↙   ↘
     X ───> C ────────────────────────> Y    X ──> Y (直接因果)
```

#### 后门路径排查与控制集求解：
1. 识别 $X$ 到 $Y$ 的所有路径：
   - 因果前门路径：$X \to Y$（直接效应）、$X \to C \to Y$（通过进店时长的间接效应）；
   - 后门路径 1：$X \leftarrow A \to Y$（由购买力构成的混杂后门）；
   - 后门路径 2：$X \leftarrow B \to Y$（由价格敏感度构成的混杂后门）；
   - 潜在路径 3：$X \leftarrow A \to S \leftarrow B \to Y$。注意在节点 $S$ 处是一个碰撞体（$A \to S \leftarrow B$），**默认已被阻断！**
2. 科学控制决策：
   - 必须阻断后门 1 和后门 2：将 $\{A, B\}$ 纳入控制变量集！
   - **严禁控制 $S$**：若在模型中加入了特征 $S$，会打开路径 3 的碰撞体后门！
   - **严禁控制 $C$**：$C$ 是因果中介，控制 $C$ 会阻断 $X \to C \to Y$ 的因果增量！
   - **最小充分控制变量集合（Minimal Sufficient Adjustment Set）**：严格为 $\{A, B\}$！

### 实验上线前必须执行的体检：两组真的平衡吗？
理论上随机化在大样本下能平衡一切，但在真实世界有限样本中，可能会因为**抽样随机抖动**或**工程代码分流故障**导致两组基线不均衡。

#### 协变量平衡性诊断指标：
1. **标准化均值差（Standardized Mean Difference, SMD / Cohen's d）**：
   $$SMD = \frac{\bar{X}_{T} - \bar{X}_{C}}{\sqrt{\frac{s_T^2 + s_C^2}{2}}}$$
   - 工业经验法则：**若每个协变量的 $|SMD| < 0.10$（更严格为 $< 0.05$），表明两组协变量平衡极佳！**
   - 为什么不用 t 检验 p 值？因为在大数据样本（如上百万人）中，极微小、毫无业务意义的均值差异（如年龄相差 0.01 岁）也会触发 $p < 0.05$ 显著报警。SMD 剥离了样本量影响，只度量真实效应量。
2. **Love 图（Love Plot）**：
   将所有协变量的 SMD 绘制在散点图上，以 0.1 为垂直基准红线，一眼审查全盘特征是否全线达标。

### 抛弃正态性假定的纯粹非参数检验：Fisher 精确检验
经典 t 检验依赖渐近大样本正态性假定。在小样本或极度偏态分布中，R.A. Fisher 提出了基于物理随机化机制本身的**置换检验（Permutation Test）**。

#### 尖锐原假设（Fisher's Sharp Null Hypothesis, $H_0$）：
处理对**每一个个体**都完全没有产生任何因果效应：
$$H_0: \tau_i = Y_i(1) - Y_i(0) = 0, \quad \forall i$$

#### 置换检验算法执行流程：
1. **计算原始检验统计量**：在真实实验数据上计算实际均值差 $T_{\text{obs}} = \bar{Y}_T - \bar{Y}_C$。
2. **重塑宇宙（置换标签）**：在 $H_0$ 为真的假定下，每个人的结果 $Y_i$ 无论分到处理组还是对照组都不会改变。将所有个体的处理标签 $D$ 随机打乱洗牌（Permute），重新计算打乱后的虚拟均值差 $T^{(b)}$。
3. **重复海量蒙特卡洛抽样**：重复洗牌 $B = 10,000$ 次，构建虚无假设下的原假设分布。
4. **计算置换 p 值**：
   $$p = \frac{1}{B} \sum_{b=1}^B I(|T^{(b)}| \ge |T_{\text{obs}}|)$$
- 核心优势：**完全不依赖任何总体概率分布假定，检验功效极度稳健**！

### 理想很丰满，现实很骨感：受试者不听话怎么办？
在医学和互联网中，你经常无法强迫用户执行策略：
- 医生给实验组患者开了降压药，但有 30% 的患者因为嫌苦拒绝吃药；
- 平台随机给实验组用户发了 100 元优惠券，但有 60% 的用户根本没有领券消费！

#### 面对不依从，绝对不能犯的两个低级错误：
1. **按实际接受处理分析（As-Treated / AT）**：将“真正吃了药的人”与“没吃药的人”对比。
   - 灾难：打破了随机化！吃药的人往往求生欲强、自律健康，重新引入恶性自选择偏差。
2. **按符合方案分析（Per-Protocol / PP）**：直接剔除所有不听话的人，只分析完全依从者。
   - 灾难：同样破坏随机化，且样本产生损耗偏误。

#### 唯一的正统基准：意向性分析（Intention-to-Treat, ITT）
- **铁律**：**“按最初随机分配的身份进行统计分析，哪怕他中途一口药都没吃，也必须算在处理组里！”**（Once randomized, always analyzed!）
- **因果内涵**：$ITT = E[Y \mid Z = 1] - E[Y \mid Z = 0]$（其中 $Z$ 为随机分配指派）。
- **现实意义**：ITT 评估的是**政策指派（Assignment to Treatment）的综合因果效应**。它极其务实，直接包含了人群现实执行损耗，是药监局（FDA）审查药物上市的强制金标准！

### 如何从不依从试验中提炼真实的药效？
虽然 ITT 保守稳健，但研发科学家依然想知道：“对于那些真正按时服药的人，药效究竟有多大？”

#### 人群依从性四象限模型（Angrist, Imbens, Rubin）：
根据个体在不同随机指派 $Z \in \{0, 1\}$ 下的实际服药行为 $D(Z)$，全人类可划分为四种潜在类别：
1. **依从者（Compliers）**：分到就吃，没分到就不吃（$D(1)=1, D(0)=0$）。**推断的唯一目标客群！**
2. **永远接受者（Always-takers）**：分不分到都想方设法去吃药（$D(1)=1, D(0)=1$）。
3. **永不接受者（Never-takers）**：分不分到都誓死不吃药（$D(1)=0, D(0)=0$）。
4. **反抗叛逆者（Defiers）**：分到偏不吃，没分到偏偷吃（$D(1)=0, D(0)=1$）。统计学通常引入**单调性假定（Monotonicity）**：排除反抗者的存在（No Defiers）。

#### 依从者平均因果效应（Complier Average Causal Effect, CACE / LATE）：
在单调性假定与排他性约束下，随机分配 $Z$ 可充当完美的**工具变量（Instrumental Variable）**！
通过 **Wald 估计量（Wald Estimator）**：
$$CACE = \frac{E[Y \mid Z = 1] - E[Y \mid Z = 0]}{E[D \mid Z = 1] - E[D \mid Z = 0]} = \frac{ITT_Y}{ITT_D}$$
- **直觉**：政策产出的结局增量 $ITT_Y$，除以实际转化成真实服药人群的依从率增量 $ITT_D$。
- **神奇缩放**：若随机发券使转化率提升了 10 分（$ITT_Y = 10$），而用券依从率净增 50%（$ITT_D = 0.5$），则真正用券人群的因果增量为 $CACE = 10 / 0.5 = 20$ 分！精准还原纯净药效。

### 区分“干预的化学作用”与“心理暗示”
在评估因果效应时，我们不仅要测量总效应，还要验证其背后的生物学或业务传导机制。

#### 安慰剂效应（Placebo Effect）与双盲设计（Double-blind）：
- 心理生理学证明：病人仅仅因为“知道自己正在接受高端治疗”，大脑分泌内啡肽就能缓解 30% 的疼痛！
- **盲法机制（Blinding）**：
  - 单盲（Single-blind）：受试者不知道自己吃的是真药还是糖丸（消除心理暗示偏差）；
  - 双盲（Double-blind）：负责问诊评估的医生和患者双双不知情（消除主观诊断打分偏见）。

#### 商业与互联网中的安慰剂检验（Placebo Checks）：
1. **伪处理检验（Fictitious Treatment）**：给对照组用户弹出一个毫无实质优惠的普通提示框，排查指标提升究竟是“大促降价的经济刺激”还是“弹窗强提醒的注意力唤醒”。
2. **伪结局检验（Negative Control Outcomes）**：检测一个理论上绝对不可能受处理影响的无关指标（如降压药不应该改变头发长度）。若伪结局显著改变，百分之百说明分流系统已遭污染或两组基础不均！

### 算例拆解：高血压新药临床试验的不依从因果核算
某医药机构进行降压新药随机双盲临床试验。
- 总样本量：2,000 名患者，严格 1:1 随机指派：
  - 实验指派组（$Z=1$）：1,000 人。其中 800 人按时服药（$D=1$），200 人中途弃药（$D=0$）；
  - 对照指派组（$Z=0$）：1,000 人，全部服用外观相同的安慰剂糖丸（$D=0$）。（严格单向不依从：对照组无法偷拿到新药）。
- 试验随访结局（收缩压降幅，mmHg，降幅数值越大代表疗效越好）：
  - 实验指派组总体平均降幅：$E[Y \mid Z=1] = 18.0$ mmHg
  - 对照指派组总体平均降幅：$E[Y \mid Z=0] = 6.0$ mmHg

#### 因果指标多维度计算：
1. **意向性分析效应（ITT）**：
   $$ITT_Y = E[Y \mid Z=1] - E[Y \mid Z=0] = 18.0 - 6.0 = 12.0 \text{ mmHg}$$
   （该药作为公共卫生处方政策，平均给受试人群带来 12 mmHg 的血压改善）。
2. **依从率因果效应（$ITT_D$）**：
   - 实验指派组服药率：$E[D \mid Z=1] = 800 / 1000 = 80\%$
   - 对照指派组服药率：$E[D \mid Z=0] = 0\%$
   $$ITT_D = 80\% - 0\% = 0.80$$
3. **依从者真实因果效应（CACE / LATE）**：
   $$CACE = \frac{ITT_Y}{ITT_D} = \frac{12.0}{0.80} = 15.0 \text{ mmHg}$$
   真实服药的依从者患者，其收缩压净改善幅度高达 15.0 mmHg！原本被 20% 弃药者稀释拉低的 12 mmHg，通过 Wald 估计量被精准复原！

### 观察性研究的因果推断起点
在缺乏随机对照试验时，我们通常退守到**基于可观测变量的选择（Selection on Observables）**假定。

#### 条件独立假定（Conditional Independence Assumption, CIA）：
$$(Y(1), Y(0)) \perp D \mid X$$
- **直觉含义**：我们虽然无法在全人群中直接对比处理组与对照组，但如果在每一个由特征 $X$（如性别、年龄、工龄、学历）精确切分出的**同质细分子人群内部**，处理分配 $D$ 就如同扔硬币一样随机独立！
- **条件期望识别公式**：
  $$E[Y(1) \mid X] = E[Y \mid D = 1, X]$$
  $$E[Y(0) \mid X] = E[Y \mid D = 0, X]$$
  由此，条件因果效应直接可由观测回归函数识别：
  $$\tau(X) = E[Y \mid D = 1, X] - E[Y \mid D = 0, X]$$
  再对 $X$ 的边缘分布求期望，即可识别出全人群因果效应 $ATE = E_X[\tau(X)]$。

### 揭开多元回归的黑匣子：FWL 定理
在多元回归模型 $Y = \alpha + \beta_1 D + \boldsymbol{\gamma}^T \mathbf{X} + \epsilon$ 中，偏回归系数 $\beta_1$ 是如何“控制了其余变量 $\mathbf{X}$ 保持不变”的？
计量经济学中著名的 **Frisch-Waugh-Lovell (FWL) 定理** 用纯粹的几何正交投影证明了惊人结论：

#### FWL 两步残差回归法：
1. **第一步（对结局做清洗）**：用控制变量 $\mathbf{X}$ 对结局 $Y$ 做 OLS 回归，提取残差 $\tilde{Y} = Y - \hat{Y}(\mathbf{X})$。残差 $\tilde{Y}$ 代表了**剔除了所有能被 $\mathbf{X}$ 解释的部分后，$Y$ 中剩余的纯净新信息**。
2. **第二步（对处理做清洗）**：用控制变量 $\mathbf{X}$ 对处理变量 $D$ 做 OLS 回归，提取残差 $\tilde{D} = D - \hat{D}(\mathbf{X})$。残差 $\tilde{D}$ 代表了**剔除了所有能被 $\mathbf{X}$ 预测的部分后，$D$ 中纯粹的外生随机波动**。
3. **第三步（纯净残差简单回归）**：将纯净残差 $\tilde{Y}$ 对纯净残差 $\tilde{D}$ 运行一个**最简单的一元回归（不带截距项）**：
   $$\hat{\beta}_1 = \frac{\sum \tilde{D}_i \tilde{Y}_i}{\sum \tilde{D}_i^2} = \frac{\text{Cov}(\tilde{D}, \tilde{Y})}{\text{Var}(\tilde{D})}$$
- **定理核心**：**由此算出的斜率，在数学上完全严格等价于多元回归中 $D$ 的偏回归系数 $\hat{\beta}_1$！**
- 深刻直觉：控制变量不是神谕，多元回归只是在代数层面上用投影矩阵强行滤掉了混杂变量对两者的线性共振！

### 遗漏了关键特征时，系数会产生多大谎言？
设真实世界因果生成机制包含两个特征（处理变量 $D$ 与混杂变量 $U$）：
$$Y_i = \beta_0 + \beta_1 D_i + \beta_2 U_i + \epsilon_i$$
（其中 $\beta_1$ 是我们梦寐以求的真实因果效应）。
若分析师未能观测到或遗漏了 $U$，错误拟合了**简略回归模型（Short Regression）**：
$$Y_i = \alpha_0 + \alpha_1 D_i + u_i$$

#### 遗漏变量偏误公式（OVB Formula）：
简略回归中计算出的系数期望值为：
$$E[\hat{\alpha}_1] = \beta_1 + \underbrace{\beta_2 \cdot \frac{\text{Cov}(D, U)}{\text{Var}(D)}}_{\text{遗漏变量偏误 (OVB)}}$$
令 $\gamma_{UD} = \frac{\text{Cov}(D, U)}{\text{Var}(D)}$ 为将 $U$ 对 $D$ 做辅助回归的斜率，简记为：
$$\text{Bias} = \beta_2 \times \gamma_{UD}$$

#### 偏误方向判别口诀：
- 若 $\beta_2 > 0$ 且 $\gamma_{UD} > 0$（同正） $\implies$ 偏误为正（**向上正偏**，虚假夸大效应）；
- 若 $\beta_2 > 0$ 且 $\gamma_{UD} < 0$（一正一负） $\implies$ 偏误为负（**向下负偏**，低估甚至反转效应）；
- **唯二偏误为 0 的条件**：
  1. $\beta_2 = 0$（遗漏的变量根本不影响结局，不是混杂）；
  2. $\gamma_{UD} = 0$（处理变量与遗漏变量严格线性无关，如 RCT！）。

### 当线性假设遭遇真实非线性世界
普通 OLS 假设 $E[Y \mid D, X]$ 关于 $X$ 是严格线性的：$Y = \beta_0 + \beta_1 D + \beta_2 X + \epsilon$。
如果真实的因果关系是高度非线性的（例如年龄对收入是倒 U 型二次曲线，或者学历与技能存在门槛乘积效应）：
- 简单的线性回归即使控制了年龄，残差中依然会残留未被消除的高阶非线性混杂！

#### 破解非线性设定偏误的三大武器：
1. **多项式与交互项展开（Polynomials & Interactions）**：
   引入高阶项 $X^2, X^3$ 以及交叉项 $D \times X$。
2. **饱和模型（Saturated Model）**：
   若控制变量是离散分类变量（如学历 4 类，地域 30 省），为每一个可能的特征交叉单元设置独立的哑变量（Dummy Variables）交互。饱和模型不对条件期望函数施加任何函数形式约束，拟合优度完美，完全免疫任何形式设定偏误！
3. **半参数与非参数估计（G-computation / 回归平滑）**：
   使用随机森林或神经网络对 $E[Y \mid D=1, X]$ 和 $E[Y \mid D=0, X]$ 分别做非线性拟合。

### 算准系数还不够，检验必须稳健
因果推断不仅需要无偏的点估计（$\hat{\beta}$），还需要极其可信的置信区间与假设检验。

#### 传统标准误崩溃的两大杀手：
1. **异方差（Heteroskedasticity）**：残差方差随自变量取值发生系统性变化（如高收入人群消费方差远高于低收入人群）。此时传统 OLS 标准误失效，必须使用 **White / Huber-White 异方差稳健标准误（HC1, HC2, HC3）**。
2. **群内自相关与组内相关（Intra-cluster Correlation）**：
   - 数据往往呈现天然的层级结构：例如同一个班级的学生、同一个商圈的商家、同一位用户的多次回访记录。
   - 组内个体的误差项存在强正相关（$\text{Cov}(\epsilon_{ig}, \epsilon_{jg}) > 0$）。
   - **严重后果**：普通标准误会错误地将同一群内的相关样本视为全新独立信息，导致样本“有效自由度”被虚假大幅夸大，**标准误被严重低估 2 到 5 倍，假阳性显著性爆表！**

#### 工业级金标准：按集群稳健标准误（Cluster-Robust SE）
- 在网约车实验中按“城市/天”聚类，在学校教育研究中按“班级/学校”聚类，在用户行为研究中按“用户 ID”聚类！

### 资深学者的排毒清单：什么变量千万不能进回归？
回归模型中绝不是控制变量越多越干净。以下四种控制属于教科书级的自杀操作：

```
坏控制类型与致偏机理：

1. 因果中介变量 (Mediators: X -> M -> Y)
   ├── 操作：把干预发生之后的中介行为 M 放进回归
   └── 恶果：拦截真实传导机制，引发过度控制偏误 (Over-controlling Bias)

2. 碰撞体变量 (Colliders: X -> C <- Y 或 X -> C <- U)
   ├── 操作：控制了处理与结局的共同结果 C
   └── 恶果：打通非因果后门管道，诱发伯克森悖论 (Collider Stratification Bias)

3. 结局的近端代理 (Proxies of Outcome: Y -> Proxy)
   ├── 操作：控制了与最终指标高度重合的后置表征
   └── 恶果：吞噬因果效应方差，使因果系数人为萎缩归零

4. 带有反向因果的同期变量 (Simultaneity Variables)
   ├── 操作：控制了在干预同时且反向影响干预的变量
   └── 恶果：引入联立因果内生性死锁
```

### 算例拆解：高阶架构师培训对薪资的因果解构
某平台研究“参加高阶架构师训练营（$D \in \{0, 1\}$）”对“跳槽年薪（$Y$，万元）”的因果效应。
真实潜在因果模型为：
$$Y_i = 20 + 8 D_i + 3 X_i + \epsilon_i$$
（真实因果净增量 $\beta_1 = 8$ 万元，$X_i$ 为跳槽前工龄年数，工龄每多 1 年薪资多 3 万元）。

#### 观测数据中的混杂关联：
经验统计显示：工龄更长的人由于技术积累更深、更有付费意愿，参加该训练营的比例更高。
拟合工龄 $X$ 对训练营 $D$ 的辅助回归方程：
$$X_i = 3.5 + 2.0 D_i + v_i \implies \gamma_{XD} = \frac{\text{Cov}(D, X)}{\text{Var}(D)} = 2.0$$
（即参训人群的工龄平均比未参训人群高出 2 年）。

#### 遗漏变量偏误核算：
若分析师遗漏了工龄 $X$，直接运行简略单变量回归 $Y = \alpha_0 + \alpha_1 D + u$：
1. **代入 OVB 公式**：
   $$E[\hat{\alpha}_1] = \beta_1 + \beta_2 \times \gamma_{XD} = 8 + 3 \times 2.0 = 8 + 6 = 14 \text{ 万元}$$
2. **偏误定量诊断**：
   - 简略回归输出的估计值高达 14 万元！
   - 其中的 6 万元（占比 $42.9\%$）完全是由工龄混杂引起的虚假偏误！
3. **FWL 正交清洗验证**：
   若将工龄 $X$ 纳入多元回归 $Y = \beta_0 + \beta_1 D + \beta_2 X + \epsilon$：
   FWL 投影首先将 $D$ 中工龄带来的那 2 年增益彻底剥离，计算残差回归，估计系数精准回归为真实的 8.0 万元！

### 如何估计出高质量的倾向得分？
倾向得分是一个条件概率 $e(X) \in (0, 1)$。

#### 1. 经典参数模型：Logistic 回归
$$\ln \left( \frac{e(X)}{1 - e(X)} \right) = \beta_0 + \boldsymbol{\beta}^T \mathbf{X} + \text{交互项} + \text{二次项}$$
- **建模目标与传统分类的根本不同**：
  - 传统机器学习分类追求极高的 AUC 或准确率（准确把 0 和 1 分开）；
  - **因果倾向得分追求的是概率的极佳校准（Calibration）与重叠重合！**
  - 如果 AUC 达到 0.99，意味着处理组和对照组被截然分开，两组完全没有共同支撑域，因果推断反而彻底完蛋！倾向得分适宜的 AUC 通常在 0.65 到 0.85 之间。

#### 2. 现代机器学习模型（GBDT / XGBoost / LightGBM）
- 优势：自动捕捉高维特征的复杂非线性边界与高阶交互项；
- 必须注意：必须使用 **Brier Score** 或 **可靠性曲线（Reliability Diagram）** 对预测概率做 Platt 缩放或等保回归校准。

### 在一维倾向得分轴上的配对艺术
有了每个人的倾向得分 $\hat{e}_i$ 后，如何为处理组用户挑选最佳对照？

#### 1. 1:1 最近邻匹配（Nearest Neighbor Matching）
- 对于每个处理组个体 $i$（得分 $e_i$），在对照组中寻找欧氏距离 $|e_i - e_j|$ 最小的个体 $j$ 配对。
- 放回匹配（With Replacement） vs 不放回匹配（Without Replacement）。

#### 2. 卡尺匹配（Caliper Matching / 限制容差）
- 最近邻的隐患：若某个处理组个体的得分为 0.85，而对照组中最高得分只有 0.40，最近邻会被迫将 0.85 与 0.40 强行配对，导致“劣质拉郎配”。
- **卡尺（Caliper）机制**：设定最大允许距离阈值（如卡尺宽取倾向得分标准差的 0.2 倍：$\delta = 0.2 \sigma_e$）。若在卡尺范围内找不到合格对照，宁可将该处理组个体舍弃（丢弃不可比样本），也绝不勉强匹配！

#### 3. 倾向得分结合马氏距离（Mahalanobis Distance）
- 在卡尺限制的倾向得分邻域内，针对极核心的业务变量（如年龄、基础病）使用马氏距离精确对齐，实现双重精细化匹配。

### IPTW 最致命的阿喀琉斯之踵：极值权重爆炸
观察权重公式：分母是 $e(X)$ 和 $1 - e(X)$。
- 如果某个个体的倾向得分极度接近 0（如 $e(X) = 0.001$），其作为处理组时的权重将瞬间暴增至 $1 / 0.001 = 1000$！
- **灾难后果**：单个极端异常样本的测量噪声被放大上千倍，直接主宰了整个因果效应的估计值，导致估计量方差发散崩溃！

#### 工业级治理三大组合拳：
1. **共同支撑域直方图审查（Overlap Diagnostics）**：
   绘制处理组与对照组的倾向得分分布核密度曲线，直观审查两组在横轴上的重叠区间。
2. **硬截断修剪（Trimming）**：
   Crump 等学者证明的最优准则：坚决剔除 $\hat{e}(X) < 0.05$ 或 $\hat{e}(X) > 0.95$（更保守取 $0.1 \sim 0.9$）的极端不可比样本。
3. **稳定加权（Stabilized Weights）**：
   将分子从 1 替换为处理的边际无条件概率：
   $$sw_i = D_i \frac{P(D=1)}{e(X_i)} + (1 - D_i) \frac{P(D=0)}{1 - e(X_i)}$$
   大幅收敛极值权重的方差膨胀，保持推断稳健。

### 算例拆解：高阶会员留存的 IPTW 逆概率加权实算
假设在一个包含 4 人的微型样本中，研究会员（$D$）对活跃度（$Y$）的影响。
已知每位用户的倾向得分 $\hat{e}_i$ 与观测结果：

| 用户 | 处理 $D_i$ | 倾向得分 $e_i$ | IPTW 权重 $w_i$ | 观测活跃度 $Y_i$ | 加权结局 $w_i Y_i$ |
| :--- | :--- | :--- | :--- | :--- | :--- |
| A | 1 | 0.80 | $1 / 0.80 = 1.25$ | 100 | 125 |
| B | 1 | 0.50 | $1 / 0.50 = 2.00$ | 80 | 160 |
| C | 0 | 0.25 | $1 / (1-0.25) = 1.33$ | 40 | 53.33 |
| D | 0 | 0.50 | $1 / (1-0.50) = 2.00$ | 50 | 100 |

#### 加权因果效应计算：
1. **处理组加权平均**：
   $$\bar{Y}_1^{\text{IPTW}} = \frac{125 + 160}{1.25 + 2.00} = \frac{285}{3.25} \approx 87.69$$
2. **对照组加权平均**：
   $$\bar{Y}_0^{\text{IPTW}} = \frac{53.33 + 100}{1.33 + 2.00} = \frac{153.33}{3.33} \approx 46.00$$
3. **因果增量 $ATE_{\text{IPTW}}$**：
   $$ATE = 87.69 - 46.00 = +41.69$$
- 对比粗暴未加权均值差：$((100+80)/2) - ((40+50)/2) = 90 - 45 = +45.0$。
- 加权成功剔除了由于 A 用户高倾向自选择（$e=0.8$）带来的泡沫虚夸！
