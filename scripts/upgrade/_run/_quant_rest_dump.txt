## 什么是证券市场微观结构？

量化交易者面对的市场从来不是教科书中抽象的光滑供求曲线，而是由一个个离散委托、微秒级时间戳、交易所撮合引擎以及有限流动性构成的复杂工程系统。
**市场微观结构（Market Microstructure）**研究的是：资产交易的具体规则、协议与机制如何影响价格形成、交易成本与流动性。

在学术界，MIT 15.401（Prof. Andrew Lo）与经典著作 Larry Harris《Trading and Exchanges: Market Microstructure for Practitioners》指出：
现代主流股票交易所（如上交所 SSE、深交所 SZSE、纽交所 NYSE、纳斯达克 NASDAQ）的核心定价机制均为**连续双向拍卖（Continuous Double Auction, CDA）**驱动的电子订单簿系统。

## 核心概念与委托类型

在限价订单簿中，交易者通过提交不同类型的委托（Orders）表达交易意图：

### 1. 限价单（Limit Order, LO）
* **严谨定义**：指定买入最高价（Bid Price）或卖出最低价（Ask Price）及数量的委托指令。
* **执行特性**：在订单簿中等待对手方匹配，**提供流动性（Liquidity Provider / Maker）**。
* **优势与代价**：控制了成交价格上限/下限，但面临**执行风险（Execution Risk）**（若价格远离则无法成交）和**逆向选择风险（Adverse Selection Risk）**（一旦成交，往往是因为对手方掌握更有利的信息）。

### 2. 市价单（Market Order, MO）
* **严谨定义**：不指定价格，要求撮合引擎以当前市场最佳可用价格立即执行指定数量的委托指令。
* **执行特性**：立即消耗订单簿挂单，**消耗流动性（Liquidity Taker / Taker）**。
* **优势与代价**：保证执行速度与确定性，但**失去价格控制权**，在流动性较浅的市场中极易遭受严重的**滑点冲击（Slippage）**。

## 限价订单簿（Limit Order Book, LOB）结构

限价订单簿是记录当前市场中所有尚未成交的限价买单和限价卖单的集合。在中国 A 股市场，行情通常分为：
* **Level 1 行情**：仅展示最优的买一至买五、卖一至卖五报价与挂单量。
* **Level 2 行情**：提供买卖十档深度、逐笔委托（Order-by-Order）与逐笔成交（Tick-by-Tick）数据。

## 核心数学度量与公式

### 1. 买卖价差（Bid-Ask Spread）
买卖价差是衡量市场即时流动性最直观的指标：

**名义名目价差（Quoted Spread）**：
$$S_t = P_{t}^{ask1} - P_{t}^{bid1}$$

**相对百分比价差（Relative Spread）**：
$$s_t = \frac{P_{t}^{ask1} - P_{t}^{bid1}}{P_{t}^{mid}}$$
其中中间价定义为：
$$P_{t}^{mid} = \frac{P_{t}^{ask1} + P_{t}^{bid1}}{2}$$

价差越小，说明做市商竞争越激烈，交易者的摩擦成本越低。

### 2. 盘口失衡度（Order Book Imbalance, OBI）
盘口失衡度用于捕捉买卖双方在第一档（或前 $k$ 档）挂单力量的倾斜程度，常用于日内超短期微观结构信号：
$$OBI_t = \frac{V_{t}^{bid1} - V_{t}^{ask1}}{V_{t}^{bid1} + V_{t}^{ask1}} \in [-1, 1]$$
* 当 $OBI_t \to +1$ 时，买一挂单极深，短线价格承受向上推力；
* 当 $OBI_t \to -1$ 时，卖盘沉重，短线存在向下压力。

### 3. 成交均价与冲击成本（Impact Cost & Slippage）
若某量化策略以市价单形式买入 $Q$ 股，由于卖一深度 $V_1 < Q$，订单必须逐档向上“吃单”：
$$\bar{P}_{exec} = \frac{\sum_{i=1}^{k} P_{ask, i} \cdot q_i}{Q}, \quad \sum_{i=1}^k q_i = Q$$
市价单所遭受的**单边滑点（Slippage）**为：
$$\Delta P = \bar{P}_{exec} - P_{mid}$$

## 为什么收益率的度量是量化研究的基石？

在量化金融中，价格序列 $P_t$ 通常是非平稳的（Non-stationary），而收益率序列（Returns）具备更好的统计平稳性质。
然而，**简单离散收益率（Simple Return）**与**连续复合对数收益率（Log Return）**在数学性质与实际应用中有着严格的适用边界，严禁混用。

---

## 严谨定义与数学推导

### 1. 简单离散收益率（Simple Return）
考虑资产在时间 $t-1$ 到 $t$ 期的价格分别为 $P_{t-1}$ 和 $P_t$（假设期间分红为 $D_t$）：
$$R_t = \frac{P_t + D_t - P_{t-1}}{P_{t-1}} = \frac{P_t + D_t}{P_{t-1}} - 1$$

* **截面资产组合可加性（Cross-sectional Additivity）**：
  若投资组合包含 $N$ 种资产，资产权重分别为 $w_1, w_2, \dots, w_N$（满足 $\sum w_i = 1$），则组合简单收益率为各资产简单收益率的**线性加权平均**：
  $$R_{p, t} = \sum_{i=1}^N w_i R_{i, t}$$
  **这一性质在投资组合优化（如 Markowitz 均值-方差模型）中是绝对成立的**。

* **时序累积非线性（Time-series Non-additivity）**：
  多期复合总简单收益率不是单期简单收益率的直接相加，而是连乘积：
  $$1 + R_{0, T} = (1 + R_1)(1 + R_2)\dots(1 + R_T) = \prod_{t=1}^T (1 + R_t)$$

---

### 2. 对数收益率（Log Return / Continuously Compounded Return）
对数收益率定义为价格比值的自然对数：
$$r_t = \ln\left(\frac{P_t + D_t}{P_{t-1}}\right) = \ln(1 + R_t)$$

* **时序完美可加性（Time-series Additivity）**：
  多期累计对数收益率等于各期单步对数收益率的**算术和**：
  $$r_{0, T} = \ln\left(\frac{P_T}{P_0}\right) = \sum_{t=1}^T r_t$$
  这一美妙性质极大简化了计量经济学推导、布朗运动与 Ito 引理的应用。

## 量是价的先行指标

在金融市场微观博弈中，**价格是共识的结果，而成交量是共识分歧与换手的度量**。

### 1. 成交量加权平均价（VWAP）

VWAP（Volume-Weighted Average Price）是机构交易员与量化执行算法最重要的基准指标：

$$VWAP = \frac{\sum_{i=1}^M P_i \cdot V_i}{\sum_{i=1}^M V_i}$$

**为什么机构关心 VWAP**：

| 角色 | 用途 |
| --- | --- |
| **买方交易员** | 考核执行质量（买入均价是否低于 VWAP）|
| **卖方交易员** | 考核执行质量（卖出均价是否高于 VWAP）|
| **量化算法** | 执行算法的目标基准（VWAP 算法）|
| **分析师** | 判断当日多空力量 |

**VWAP 的解读**：

* 当现价 $P_t > VWAP$ 时，表明日内买方整体处于盈利状态，盘面偏多；
* 当现价 $P_t < VWAP$ 时，表明日内追高者大部分被套牢，盘面承压。

## 金融行情的金字塔结构

在量化交易领域，数据按生成时延与聚合粒度自底向上分为四个核心层级（参考 Larry Harris《Market Microstructure for Practitioners》）：

1. **逐笔数据（Tick / Transaction Data）**：
   * 交易所撮合成交的原子记录，包含精准到毫秒或微秒的时间戳、成交价格、成交股数、买卖方向（主动买盘/主动卖盘）、成交序号。
   * 特点：数据量极大（A股全市场单日 Tick 超过 5000 万条），信噪比低，多用于高频做市、订单流失衡分析与微观冲击成本建模。
2. **深度盘口（Level-2 / Order Book Snapshot）**：
   * 交易所定期切片广播的五档或十档买卖委托队列，包含各档位委托价格、挂单量及委买委卖总额。
   * 广播频率通常为 200ms 至 3000ms 一次（A股 Level-2 通常为 3 秒一次快照）。
3. **聚合 Bar（Minute / Daily Bar，K线）**：
   * 将一段时间内的所有 Tick 聚合为五个核心统计量：开盘价（Open）、最高价（High）、最低价（Low）、收盘价（Close）、成交量（Volume）与成交额（Amount），即 OHLCV。
4. **低频基本面与宏观数据**：
   * 财报（季报、年报）、分红派息公告、行业宏观指标等，更新频率为季度或月度。

          │  日 / 分钟 K 线 (Bar 级)   │

## REST Polling vs WebSocket Streaming

量化系统获取行情与交易通道主要依赖两种网络通信协议：

### 1. RESTful API（基于 HTTP/HTTPS）
* **通信模型**：客户端发起请求（Request），服务端返回响应（Response），短连接无状态。
* **适用场景**：历史行情批量下载、日终数据结算、账户资产查询、低频选股。
* **瓶颈**：每次请求都需建立 TCP 握手与 TLS 认证，握手延迟（Round Trip Time, RTT）通常在 20ms-200ms 以上；频繁轮询（Polling）会极大浪费带宽并触发服务商的频次限制（Rate Limit，如 429 Too Many Requests）。

### 2. WebSocket 双向长连接
* **通信模型**：通过 HTTP 协议发起握手并升级（Upgrade: websocket），在单条持久 TCP 连接上进行全双工实时数据帧传输。
* **适用场景**：实盘实时盘口监听、逐笔行情推送、秒级/毫秒级订单状态推送。
* **核心机制**：
  * **心跳维持（Ping-Pong / Heartbeat）**：客户端与网关每隔 10~30 秒发送 Ping 帧，若连续超时未收到 Pong 则判定断线，立即触发重连机制。
  * **重连退避（Exponential Backoff）**：断线后采用指数退避重连（如 1s, 2s, 4s, 8s），防止服务器雪崩。

```
   REST (请求-响应):
   Client ── Request (HTTP GET) ──> Broker Server
   Client <── Response (JSON) ───── Broker Server  (延迟 50-200ms)

   WebSocket (全双工流式推送):
   Client ── 握手升级 (Upgrade) ──> Broker Server
   Client <── 逐笔行情流 (Push) ─── Broker Server  (延迟 < 5ms)
   Client ── Ping / Pong 心跳 ──── Broker Server
```

## 金融数据清洗与持久化标准

### 1. 脏数据与异常值过滤
* **乌龙指与刺客价格（Spike / Fat-finger）**：由于交易所偶发网络乱序或对敲乌龙指，可能出现偏离正常价格 10% 以上的单笔成交。常用基于滚动中位数绝对偏差（MAD）或滚动布林带通道过滤异常极值。
* **时间戳乱序（Out-of-Order Packets）**：网络传输导致后产生的订单先到达，必须根据交易所物理序号（SeqNum）进行重排序。
* **非交易时间脏数据**：集合竞价前、午间休市或收盘后推送的测试行情包，必须通过交易日历过滤器直接剔除。

### 2. 停牌股票处理策略
A股经常出现因重大资产重组、财务暴雷而长期停牌（数天至数月）。
* **前向填充（Forward Fill / ffill）**：将上一交易日收盘价填充至停牌日。
* **警惕**：如果策略在此期间发出买卖信号，回测引擎必须强制检查当前是否处于停牌状态（`is_suspended == True`），严禁在停牌期间虚拟成交！

### 3. 金融时序存储架构对比
* **CSV 纯文本**：体积大、解析慢、无类型系统，仅适合调试查看。
* **Parquet / Feather（列式存储）**：利用 Snappy 压缩算法，对时间戳和浮点数压缩率高，查询单列（如 Close）性能比 CSV 快数十倍，是中低频量化研究首选。
* **ClickHouse / DolphinDB**：高性能分布式时序数据库，专为千亿级 Tick 和 L2 深度盘口设计，支持毫秒级分布式聚合计算。

## 累积复权因子的数学实现

在机构级量化系统中，行情库通常不直接存储多套前/后复权价格，而是存储一套**原始未复权行情（Raw Close）**与一套**复权因子序列（Adjustment Factors）**。

### 1. 拆分调整因子（Split Factor）与连乘算法
设第 $t$ 次除权事件的调整系数为：
$$f_t = \frac{P_{ex, t}}{P_{close, t}}$$

* **后复权因子 $A_{hfq, t}$**：
  $$A_{hfq, t} = \prod_{\tau \le t} \frac{1}{f_\tau}$$
  后复权价格：$P_{hfq, t} = P_{raw, t} \cdot A_{hfq, t}$。
* **前复权因子 $A_{qfq, t}$**：
  以最新交易日 $T$ 的后复权因子为基准做归一化：
  $$A_{qfq, t} = \frac{A_{hfq, t}}{A_{hfq, T}}$$
  前复权价格：$P_{qfq, t} = P_{raw, t} \cdot A_{qfq, t}$。
  最新交易日 $T$ 的前复权因子恰好为 $1.0$，历史前复权价格均小于等于原始价。

## 两种截然不同的动量效应

在学术界与量化投资界，「动量（Momentum）」分为两大流派：

### 1. 截面动量（Cross-Sectional Momentum, CSMOM）
* **代表文献**：Jegadeesh & Titman (1993) *Returns to Buying Winners and Selling Losers*。
* **核心逻辑**：在同一截面时间点，对股票池内所有资产按过去回看窗口（如过去 3~12 个月）的累积收益率进行排序。
* **策略构建**：做多排名前 $10\%$ 的「赢家组合（Winners）」，同时做空排名后 $10\%$ 的「输家组合（Losers）」，获取相对强弱差额收益。

### 2. 时间序列动量（Time-Series Momentum / Trend, TSMOM）
* **代表文献**：Moskowitz, Ooi, Pedersen (2012) *Time Series Momentum* (JFE)。
* **核心逻辑**：不与其他资产横向对比，仅考察资产自身的绝对历史趋势：
  $$r_{t-k, t} > 0 \implies \text{做多}, \quad r_{t-k, t} < 0 \implies \text{做空或空仓}$$
* **优势**：在重大宏观黑天鹅与跨资产危机爆发时，时间序列动量（常用于 CTA 管理期货基金）能够快速做空走弱的大宗商品或股指，表现出极强的「危机 Alpha（Crisis Alpha）」特性。

## 寻找孪生资产的价值纽带

配对交易（Pairs Trading）由摩根士丹利的 Nunzio Tartaglia 量化团队在 1980 年代首创：

### 1. 资产选择：相关性 vs 协整性（Cointegration）
* **相关性（Correlation）**：仅衡量两只股票短期收益率是否同涨同跌，不能保证两者价差长期不会永久发散（如两只股票长期收益率相关但价格绝对差距越来越大）。
* **协整性（Cointegration）**：指两只非平稳的价格序列 $P_A$ 与 $P_B$，存在一个线性组合系数 $\gamma$，使得价差：
  $$\text{Spread}_t = P_{A, t} - \gamma P_{B, t}$$
  是一个**平稳时序（Stationary Series）**！

### 2. 动态 Z-Score 标准化开平仓规则
计算滚动窗口（如 30 日）价差均值 $\mu_t$ 与标准差 $\sigma_t$：
$$Z_t = \frac{\text{Spread}_t - \mu_t}{\sigma_t}$$
* **做空价差（Short Spread）**：当 $Z_t > +2.0$（价差处于历史统计极端高位），做空股票 A、做多 $\gamma$ 倍股票 B；
* **做多价差（Long Spread）**：当 $Z_t < -2.0$（价差处于历史统计极端低位），做多股票 A、做空 $\gamma$ 倍股票 B；
* **均值止盈平仓**：当 $Z_t$ 回归至 $[-0.5, +0.5]$ 均衡中枢区间时全额平仓；
* **硬性风控止损**：当 $|Z_t| > 3.5$ 时，说明两家公司基本面发生永久性背离（如其中一家遭遇财务造假或技术颠覆），必须无条件止损！

### 1. 布林带（Bollinger Bands）结构

## 原始因子的标准化清洗流水线

从基本面财报或量价数据中直接提取的原始因子，含有大量的异常值分布倾斜以及行业/市值偏差，必须经过严格的预处理流水线：

### 1. 中位数绝对偏差去极值（MAD Winsorization）
传统三倍标准差去极值受均值极值污染严重。量化工业界标准采用基于中位数的绝对偏差（Median Absolute Deviation, MAD）：
$$Med = \text{median}(X), \quad MAD = \text{median}(|X - Med|)$$
设置裁剪区间 $[Med - 3 \times 1.4826 \times MAD, Med + 3 \times 1.4826 \times MAD]$，将超出边界的值压回边界。

### 2. 截面 Z-Score 标准化
$$Z_i = \frac{X_i - \bar{X}}{\sigma_X}$$
消除不同因子之间的量纲差异，使得截面均值为 0，方差为 1。

### 3. 行业与市值中性化（Neutralization）
* **为什么必须中性化**：如果不做中性化，一个「低市盈率 PE」因子可能会选出全部是银行股与地产股，策略超额收益会被行业大盘周期与巨头暴跌完全绑架。
* **多元截面线性回归**：

  回归后的**残差 $\epsilon_i$** 即为剔除了行业配置偏好与市值规模效应后的**纯净 Alpha 因子**！

## 消除重叠样本带来的伪独立性

在通用机器学习中，通常假设样本之间独立同分布（I.I.D.）。但在使用三重屏障法时，样本 $t_1$ 的持仓期可能持续到 $t_1 + 4$，而样本 $t_2$（在 $t_1+1$ 入场）的持仓期持续到 $t_2 + 3$。
两者的事件时间跨度高度重叠，共享了同一段行情收益，导致样本**高度不独立**！

### 1. 标签并发度（Label Concurrency）
设在任意时刻 $t$，市场上正在并发持仓的活跃事件数量为 $c_t$。
若某一天有 10 个策略事件同时处于开仓状态，则当天每一个事件能提供的信息量仅为普通独立事件的十分之一！

### 2. 平均唯一度（Average Uniqueness）
样本 $i$ 在其持仓存续期 $[t_{i, 0}, t_{i, 1}]$ 内的平均唯一度为：
$$\bar{u}_i = \frac{1}{t_{i, 1} - t_{i, 0} + 1} \sum_{t = t_{i, 0}}^{t_{i, 1}} \frac{1}{c_t}$$
在喂入决策树或神经网络进行训练时，必须以平均唯一度 $\bar{u}_i$ 作为样本权重（Sample Weight），有效抑制重叠样本对损失函数的重复计票过拟合！

## 特征重要性评估的真伪辨析

如何科学评估哪些因子真正对模型做出了实质预测贡献？

### 1. 平均不纯度减少法（Mean Decrease Impurity, MDI / Gini Importance）
* **计算原理**：统计某特征在所有树节点分裂时带来的方差减少量或基尼增益总和。
* **致命缺陷（大幅高估）**：
  * **基数偏差（Cardinality Bias）**：对于连续型高方差噪声特征，树有更多切分点选择，MDI 会人为严重高估该无用特征的重要性！
  * **无法反映样本外泛化**：MDI 完全在训练集内计算，把过拟合噪声当成核心贡献。

### 2. 平均降低精度法（Mean Decrease Accuracy, MDA / Permutation Importance）
Leo Breiman (2001) 与 Marcos López de Prado 强烈推荐的**样本外置换检验法**：
1. 模型在训练集训练完毕后，在**独立的样本外（OOS）测试集**上评估基线预测性能（如 $R^2$ 或准确率 $Score_{base}$）；
2. 针对特征 $j$，将其在 OOS 测试集中的列数值进行**随机洗牌打乱（Permutation / Shuffling）**，彻底破坏该特征与目标之间的关联，同时保持该特征自身的边缘统计分布不变；
3. 将洗牌后的数据重新送入模型预测，计算性能下降幅度：
   $$MDA_j = Score_{base} - Score_{permuted, j}$$
* **结论**：若洗牌后测试集性能剧烈暴跌，说明特征 $j$ 至关重要；若洗牌后性能毫无变化甚至微升，说明特征 $j$ 是纯冗余噪音！

## 破除共线性带来的重要性稀释

当特征库中存在高度相关的孪生因子时（例如 5 日均线、10 日均线、20 日均线）：
* **MDA 的局限（Substitution Effect）**：当你打乱 5 日均线时，模型可以通过 10 日均线作为完美替代品继续完成预测，导致 5 日均线测出的 MDA 几乎为零，研究员会误将核心因子当作垃圾因子丢弃！

### 聚类特征重要性（Clustered Feature Importance, CFI）
1. 先对全部候选特征计算相关系数矩阵，利用层次聚类（Hierarchical Clustering）将高度共线性的因子聚为若干个独立因子簇（Clusters）；
2. 置换测试时，**对整个簇内的所有关联特征同时进行联合洗牌打乱**；
3. 计算簇级 MDA，彻底克服因子替代效应，精准识别真正的核心因子家族！

## 释放低波动资产的收益潜力

风险平价虽然极其稳健、抗暴跌能力极强，但其不加杠杆时的年化收益往往较低（因为大比例配置了低波动的低收益国债）。

### 1. 组合杠杆放大（Leverage Mechanism）
为了让稳健的风险平价组合收益率匹敌纯股票市场，机构通常使用国债期货（如 10 年期国债期货）以较低的借贷成本建立 $2\sim 3$ 倍的杠杆：
$$w_{levered} = L \cdot w_{ERC}, \quad L = \frac{\sigma_{target}}{\sigma_{ERC}}$$
例如：原生 ERC 组合波动率仅 $5\%$，设定目标波动率为 $10\%$，则加 $2$ 倍杠杆，夏普比率保持不变，但绝对收益率翻倍！

### 2. 动态波动率目标化机制（Vol-Targeting）
每日监控近期已实现波动率 $\hat{\sigma}_t$，根据目标波动率 $\sigma^*$ 动态微调每日总杠杆仓位：
$$\text{Leverage}_t = \min\left(L_{\max}, \frac{\sigma^*}{\hat{\sigma}_t}\right)$$
当市场风平浪静波动收缩时，自动适度提高杠杆；当市场爆发危机、波动飙升时，自动强制去杠杆平仓，形成无须预测的自动化风控保护！

## VaR 的致命数学缺陷：不满足次可加性

Artzner et al. (1999) 在经典论文《Coherent Measures of Risk》中提出了**一致性风险度量公理体系**。任何合格的风险度量指标 $\rho(X)$ 必须满足四个公理：
1. **平移不变性（Translation Invariance）**：$\rho(X + c) = \rho(X) - c$；
2. **正齐次性（Positive Homogeneity）**：$\rho(\lambda X) = \lambda \rho(X) \quad (\lambda > 0)$；
3. **单调性（Monotonicity）**：$X \le Y \implies \rho(X) \ge \rho(Y)$；
4. **次可加性（Subadditivity）**：**组合的风险必须小于等于各资产风险之和**：
   $$\rho(X + Y) \le \rho(X) + \rho(Y)$$

### VaR 违背次可加性的灾难
在非凸极端厚尾分布下，两个各自独立的资产组合，合并后的 $VaR$ 可能**大于**两者 $VaR$ 之和！这在经济学上彻底粉碎了「分散化降低风险」的常识。

### 条件在险价值（CVaR / Expected Shortfall, ES）
CVaR 衡量的是：**当损失突破了 VaR 阈值后，落入尾部极端灾难时的平均预期损失金额**：
$$CVaR_\alpha = E[\text{Loss} \mid \text{Loss} > VaR_\alpha]$$
* **CVaR 是严格数学一致性风险度量（Coherent Risk Measure）**；
* 能够完美捕捉极端断崖暴跌深度，巴塞尔协议 III（FRTB 框架）已全面采用 97.5% 置信度的 Expected Shortfall 代替旧的 99% VaR！

## 为什么量化交易严禁裸写 Python for 循环？

**核心矛盾**：Python 是动态类型解释型语言，每次循环都要做类型检查、对象装箱/拆箱、指针寻址。

    # 纯 Python 循环：慢
    result = []
    for i in range(len(prices)):
        result.append(prices[i] * factor[i])
    
    # 每次迭代的开销：
    #   ① 从 list 取元素（PyObject* 解引用）
    #   ② 检查类型（int? float? Decimal?）
    #   ③ 调用 __mul__（动态分派）
    #   ④ 创建新的 PyObject（装箱）
    #   ⑤ append 到 list（可能触发扩容）

**NumPy 的做法**：连续内存块 + C 循环 + SIMD 指令。

    # 向量化：快 50~100 倍
    result = prices * factor

**实测数据**（100 万次乘法）：

| 方法 | 耗时 | 相对速度 |
| --- | --- | --- |
| Python for 循环 | ~120 ms | 1× |
| 列表推导式 | ~80 ms | 1.5× |
| **NumPy 向量化** | **~1.2 ms** | **100×** |

**关键**：差距不是常数倍，而是**随数据量放大**。回测 10 年日线（2500 天 × 500 只股票）就是 125 万次运算。

## MACD：快慢 EMA 之差

**计算步骤**：

    ① EMA_fast = close.ewm(span=12).mean()
    ② EMA_slow = close.ewm(span=26).mean()
    ③ DIF = EMA_fast - EMA_slow
    ④ DEA = DIF.ewm(span=9).mean()
    ⑤ MACD = 2 × (DIF - DEA)

<MACDDemo />

**纯 Pandas 实现**：

    def macd(close, fast=12, slow=26, signal=9):
        ema_fast = close.ewm(span=fast, adjust=False).mean()
        ema_slow = close.ewm(span=slow, adjust=False).mean()
        dif = ema_fast - ema_slow
        dea = dif.ewm(span=signal, adjust=False).mean()
        hist = 2 * (dif - dea)
        return dif, dea, hist

**关键参数 `adjust=False`**：

| adjust | 公式 | 特点 |
| --- | --- | --- |
| **True**（默认） | 加权平均，权重随样本数变化 | 前期不稳定 |
| **False** | 递推式 `EMA_t = α·P_t + (1-α)·EMA_{t-1}` | **与券商软件一致** |

**必须用 `adjust=False`**——否则结果和通达信/同花顺对不上。

## 与实盘完全同构的事件流状态机

事件驱动引擎通过一个死循环调度器（Scheduler）与优先级事件队列（Event Queue），精确按物理时间戳逐步推送市场切片：

```
  ┌──────────────┐
  │ MarketEvent  │ 交易所推送最新 Tick / Bar
  └──────┬───────┘
         │ (被 Strategy 消费)
  ┌──────▼───────┐
  │ SignalEvent  │ 策略计算因子产生目标权重 (如: 买入 300 股)
  └──────┬───────┘
         │ (被 Portfolio / Risk 审计)
  ┌──────▼───────┐
  │  OrderEvent  │ 组合风控审核通过，向模拟撮合网关生成限价单
  └──────┬───────┘
         │ (被 ExecutionHandler 撮合)
  ┌──────▼───────┐
  │  FillEvent   │ 订单按深度盘口撮合成交，扣除资金并更新持仓
  └──────────────┘
```

### 订单状态机（Order FSM）
真实交易所的订单流转是严格的异步有限状态机：
`PendingNew (待报) -> New (已报) -> PartiallyFilled (部分成交) -> Filled (全部成交) / Canceled (已撤销) / Rejected (被废单)`。
事件驱动引擎能够完美复现撤单延迟、挂单撤单费用以及订单未完成时的风控拦截。

## 决定策略生死的微观摩擦成本

无数在学术论文中表现惊艳的高夏普策略，一旦实盘便立即亏损累累，核心罪魁祸首在于对交易摩擦的严重低估：

### 1. 滑点模型（Slippage Models）
* **固定滑点（Fixed Tick Slippage）**：每笔成交固定让利 $1\sim 2$ 个最小变动价位（如 A 股每股让利 0.01~0.02 元）。
* **比例滑点（Percentage Slippage）**：按成交金额固定扣除万分之五至千分之二。
* **基于成交量占比的非线性冲击模型（Volume Share Impact）**：
  $$\text{Slippage Pct} = \eta \cdot \left(\frac{V_{order}}{V_{market}}\right)^\alpha$$
  当你的订单量占据市场当期成交量 $10\%$ 以上时，滑点将呈超线性爆炸式上升！

### 2. A 股全套法定税费结构
* **佣金（Commission）**：双边征收，通常为成交额的万分之 1 至万分之 2.5，每笔最低 5 元；
* **印花税（Stamp Duty）**：**单边卖出征收**，目前为成交金额的千分之 0.5（2023 年 8 月减半调整后）；
* **过户费（Transfer Fee）**：双边征收，中国结算按成交额的十万分之 1（0.001%）收取。

### 3. A 股极端流动性限制撮合规则
* **一字涨停**：回测引擎严禁买入（因实盘封单数千万股无法排队买到）；
* **一字跌停**：回测引擎严禁卖出平仓止损；
* **停牌股票**：所有委托直接判定为废单（Rejected）。

======== quant-backtest-c3 样本外验证、回测过拟合与数据窥探检验
---- quant-backtest-c3-l3 压缩夏普比率（Deflated Sharpe Ratio, DSR） len 661

## 剔除测试偏差后的真实策略成色

Marcos López de Prado (2014) 在《Journal of Portfolio Management》提出了**压缩夏普比率（Deflated Sharpe Ratio, DSR）**模型。

### 1. 考虑多重测试下的预期最高夏普比率
根据极值理论，对 $K$ 次方差为 $\sigma_{SR}^2$ 的零 Alpha 独立策略进行多次回测，所观察到的**最大夏普比率期望值**为：
$$E[\max_K(SR)] \approx (1 - \gamma) Z^{-1}\left(1 - \frac{1}{K}\right) + \gamma Z^{-1}\left(1 - \frac{1}{K \cdot e}\right)$$
其中 $\gamma \approx 0.5772$ 为欧拉-马歇罗尼常数，$Z^{-1}$ 为标准正态分位数函数。
* **结论**：测试了 10,000 个策略后，即使纯靠运气，期望最高夏普也能达到 2.0 以上！

### 2. DSR 核心检验逻辑
DSR 计算在给定测试次数 $K$、收益率偏度 $\hat{S}$、峰度 $\hat{K}$ 与样本长度 $T$ 的条件下，所汇报的夏普比率 $SR$ 真正显著超越基线运气水平的统计概率：
$$DSR = P\left(SR > E[\max_K(SR)]\right)$$
只有当 $DSR > 0.95$ 时，才承认该策略通过了真正的统计显著性考验！
