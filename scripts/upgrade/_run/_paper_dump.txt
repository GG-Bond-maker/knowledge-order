## 回顾：RNN 的根本问题

第 1 篇讲到，RNN 的梯度是连乘的：

    ∂L/∂h_1 = ∂L/∂h_T · ∏ ∂h_t/∂h_{t-1}
    每步乘 diag(tanh'(z)) · W_hh

**tanh' 最大 1，通常 0.1~0.25**，50 步后梯度约 1e-31。

**LSTM 的核心思路**：

> 不要强迫梯度穿过 tanh 的"挤压"——
> 给它一条**加法**的通道，让梯度可以直接流过。

<RNNvsLSTMDemo />

## LSTM 的两个关键设计

### 设计一：细胞状态（Cell State）

**新增一条贯穿所有时间步的"传送带"**：

    c_t = f_t ⊙ c_{t-1} + i_t ⊙ g_t

**关键**：这是**加法**，不是乘法。

**为什么加法重要**：

| 操作 | 梯度 |
| --- | --- |
| **乘法**：`h_t = W·h_{t-1}` | `∂h_t/∂h_{t-1} = W`（连乘衰减） |
| **加法**：`c_t = c_{t-1} + ...` | `∂c_t/∂c_{t-1} = 1`（**梯度直通**） |

## 问题：RNN 也会过拟合

LSTM 有 4 组门，参数量是 RNN 的 4 倍。
在大数据集上这没问题，但在**小数据集**上容易过拟合。

**自然的想法**：像 CNN 那样加 Dropout。

**但直接加会出问题。**

## 为什么普通 Dropout 在 RNN 上失效

### 普通 Dropout 的做法

    h_t = tanh(W_hh · h_{t-1} + W_xh · x_t + b)
    h_t = dropout(h_t)        # ← 每步随机丢弃

**问题**：**每个时间步的 mask 都不同**。

<DropoutInRNNDemo />

### 灾难性后果

**时间步 1**：

    h_1 = [0.5, 0.0, 0.3]     ← 第 2 维被丢弃

**时间步 2**：

    h_2 = [0.4, 0.8, 0.0]     ← 第 3 维被丢弃

**问题**：**信息在时间上被随机切断**。

LSTM 的"记忆"依赖 h 的连续传递。
如果每个时间步都随机丢弃不同的维度，
**记忆就变成了噪声**。

**类比**：
- 正确做法：整段对话中"某个人一直不说话"（一致的信息缺失）

## 一个根本问题：如何选择模型

假设你有一组数据点，想拟合一条曲线：

    (1, 2.1), (2, 4.2), (3, 5.9), (4, 8.1), (5, 10.2)

**三个候选模型**：

| 模型 | 参数个数 | 拟合效果 |
| --- | --- | --- |
| **直线** y = ax + b | 2 | 还行 |
| **二次** y = ax² + bx + c | 3 | 更好 |
| **四次** y = ax⁴ + ... + e | 5 | **完美穿过每个点** |

**问题**：四次多项式误差为 0，是不是最好的模型？

**答案：不是。** 它过拟合了——把噪声也当成了规律。

**但怎么定量判断"过拟合"？** 这就是 MDL 要回答的。

## MDL 的核心思想

> **最好的模型，是能把数据压缩得最短的模型。**

**为什么**：

    模型 + 用模型描述的数据 = 总描述长度

    简单模型 → 模型本身短，但数据描述长（拟合差）
    复杂模型 → 模型本身长，但数据描述短（拟合好）

    **最优模型在两者之间取得平衡**

<MDLTradeoffDemo />

**关键洞察**：**"压缩"和"学习"是同一件事**。

如果你能真正压缩数据，说明你发现了数据中的规律。
随机数据无法压缩（没有规律可学）。

## 核心问题：如何"描述"一个神经网络

第 1 篇讲了 MDL 的两部分编码：

    L(数据) = L(模型) + L(数据|模型)

**对于神经网络**：

| 部分 | 含义 |
| --- | --- |
| **L(模型)** | 描述所有权重需要多少比特 |
| **L(数据|模型)** | 给定权重后，描述数据（即预测误差） |

**问题**：**如何量化"描述权重需要多少比特"？**

一个 float32 权重是 32 比特。6000 万参数就是 **19 亿比特**（240 MB）。

**Hinton 的关键洞察**：

> **权重的"精度"决定了描述长度。**
> 如果权重可以是"模糊的"（低精度），描述就短；
> 如果必须"精确"，描述就长。

## 一个根本问题：什么是"随机"

**直觉**：随机 = 没有规律。

**但怎么严格定义**？

考虑三个 20 位二进制串：

| 串 | 描述 | 是随机的吗 |
| --- | --- | --- |
| `00000000000000000000` | 20 个 0 | ❌ 有明显规律 |
| `01010101010101010101` | 交替 | ❌ 有明显规律 |
| `11010010101100100101` | 看不出规律 | ✅ 直觉上随机 |

## 柯尔莫哥洛夫复杂度的定义

**核心定义**：

    K(x) = 能生成 x 的最短程序的长度（比特）

**例子**：

| 串 | 最短程序 | K(x) |
| --- | --- | --- |
| `"0"*20` | `print("0"*20)` | ~50 比特（程序本身长度） |
| `"01"*10` | `print("01"*10)` | ~55 比特 |
| 随机 20 位 | `print("110100...")` | ~20 比特 + 程序框架 |

**等等，这看起来反了**——随机串的 K 更小？

**修正**：应该看**"程序长度"而非"输出长度"**。

## RNN 的根本瓶颈

**RNN/LSTM 的工作方式**：一个词一个词地处理。

    词1 → 词2 → 词3 → ... → 词n

**问题 1：无法并行**

第 5 个词必须等第 4 个词算完。
一句 100 个词的话，就要串行算 100 步。
**GPU 有上万个核，却只能用到 1 个。**

**问题 2：长距离依赖衰减**

第 1 个词的信息要传到第 100 个词，
中间经过 99 次变换，信号已经很弱了。

**问题 3：梯度消失**

反向传播要穿过 100 个时间步，梯度连乘后趋近于 0。

## Transformer 的核心洞察

## LSTM 记忆的问题

**LSTM 的记忆是"扁平"的**：

    c_t ∈ R^H    （单个向量，H 维）

**问题**：**维度之间没有显式交互**。

**例子**：假设记忆要表示 3 个实体的状态：

    c = [实体1_位置, 实体1_速度, 实体2_位置, 实体2_速度, 实体3_位置, ...]

**问题**：

| 问题 | 说明 |
| --- | --- |
| **无结构** | 维度只是"槽位"，不知道哪个属于哪个实体 |
| **无交互** | 实体1 和实体2 的关系无法显式建模 |
| **难扩展** | 增加实体就要加维度，且要重新学 |
| **干扰** | 更新实体1 可能影响实体2 的表示 |

## 上一章的遗留问题

第 2 章讲了 ResNet 的核心：

    y = F(x) + x

**梯度**：`∂y/∂x = ∂F/∂x + 1`

**但有个问题**：**原版 ResNet 的 `x` 真的是"纯 x"吗？**

看原版结构：

    x → Conv → BN → ReLU → Conv → BN → (+x) → ReLU → y

**注意最后的 ReLU**：它在加法**之后**。

**所以实际是**：

    y = ReLU(F(x) + x)

**问题**：`ReLU` 会截断负值！

**这意味着**：

    如果 F(x) + x < 0，输出被截为 0
    梯度 ∂y/∂x 在负区为 0 → **捷径被破坏**！
