### 2.5 CMU — 11-766 Large Language Model Applications（Spring 2026）

- **URL**：https://cmu-llms.org/ ｜大纲 https://cmu-llms.org/syllabus/ ｜课表 https://cmu-llms.org/schedule/
- **定位原文**："Large language models are used today for many more applications than just modelling language... ranging from **web agents and retrieval systems** to music generation and coding and writing assistants."

### 3.1 关于 MIT OCW 全量枚举的说明（方法可复现）

```bash
curl -s -A "Mozilla/5.0" -L "https://ocw.mit.edu/sitemap.xml" -o sitemap.xml
grep -o "https://ocw.mit.edu/courses/[^<]*" sitemap.xml | sed 's|/sitemap.xml||' | sort -u > ocw_courses.txt
# 2590 门课
grep -Ei "automation|automat|agent|workflow|rpa|orchestr" ocw_courses.txt
```

- 精确命中 `automation` 的：**0 门**

### 4.3 建议：这门课应该由哪几部分构成

综合以上，**「AI 自动化」不能照搬任何单一大学课程**。理由是：

1. Berkeley LLM Agents MOOC（F24+SP25）覆盖了 Agent 基础、工具、多 Agent、评测、代码生成，但**完全不讲工作流编排平台和 RPA**，也不讲流程建模。
2. Stanford CS329T 是**最好的"Agent 工程 + 评测"范本**（每个架构都配 eval），但只有 10 周、70% 是项目，没有系统化的平台教学。
3. CMU 11-766 是**最好的"LLM 应用全景"**，但偏应用广度、缺自动化工程深度。
4. MIT 16.410 / 6.034 / CS50 AI 提供**规划、搜索、约束、规则系统**的经典地基 —— 这是"为什么 Agent 会规划失败"的理论解释，任何厂商文档都给不了。
5. **工作流平台 + RPA 是纯工程技能，大学里没有**，必须自建，来源只能是厂商文档。

因此建议的构成逻辑是：**经典自动化地基（大学）→ Agent 工程（大学 + 论文）→ 平台与 RPA（厂商）→ 评测与运维（大学 + 厂商）→ 综合实战（自建）**。

## 6. 附：本报告使用的可复现抓取方法

```python
# fetch.py —— 带缓存、UA、gzip 解压、301 跟随、UTF-8 输出的抓取器
import sys, io, os, re, json, gzip, zlib, hashlib
import urllib.request, urllib.error, urllib.parse

try:
    sys.stdout.reconfigure(encoding='utf-8', errors='replace')
    sys.stderr.reconfigure(encoding='utf-8', errors='replace')
except Exception:
    pass

UA = ("Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 "
      "(KHTML, like Gecko) Chrome/126.0.0.0 Safari/537.36")
```

关键实现要点（踩过的坑）：

1. **响应头必须小写归一化**：Berkeley 的 `www2.eecs.berkeley.edu` 返回 `Content-Encoding: GZIP`（大写），若按 `headers.get("Content-Encoding")` 精确匹配会漏掉，导致解压出二进制乱码。
2. **301 必须跟随，但要防自指**：OCW 的 `pages/xxx/` → `resources/xxx/index.html` 是有效跳转；但 `resources/xxx/index.html` 会 301 指回自己，需判断 `nxt != url` 否则无限循环。
3. **OCW 正文在 `course-home-grid` 之后**：`html_to_text` 全文抽取会先吐出上百行导航，必须从该锚点切片再抽取。
4. **OCW 站内搜索是 JS 渲染**，`/search/?q=` 只返回 532 字节空壳。替代方案是 `sitemap.xml` 全量枚举（2590 门课）。
5. **搜索引擎全部不可用**（Bing 强制本地化、DDG/Brave/Qwant/Startpage/Yahoo 超时、Mojeek 出 Captcha）。本报告因此**完全基于已知 URL 直接探测 + 官方 sitemap**，未使用任何搜索结果 —— 这反而提高了来源可信度。
