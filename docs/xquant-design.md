## 0. 一句话结论

原书是**一本"零基础 + AI 编程工具"的量化入门书**，主线是「把投资想法写成 spec → 让 AI 跑实验 → 看懂指标 → 怀疑结论」；它的知识点与我们已有的 10 门量化课程**大面积重叠但浅得多**，真正的增量是**教学法编排**（单变量对照实验、锯齿/山峰、五个陷阱清单、四阶段三环节地图）。

因此建议：**新增 1 门入门课**（不改动现有 10 门），把它定位成量化学习地图的**第 0 站**，内容按本站 A 级规格重写，工具操作类内容全部裁掉，补充原书缺失的严谨知识点，并把所有代码示例改写为**浏览器内离线可跑**。

## 5. 三个必须统一的技术口径

1. **所有 demo 必须离线可跑**。本站 Pyodide 只带 numpy / pandas / matplotlib，**无网络、无 yfinance/akshare、无 open-xquant**。
   → 原书所有"下载 ETF 数据"的代码改造为：**内嵌固定种子生成的合成行情**（可复现）+ 少量真实历史收益率的静态小表（如沪深300/纳指100/黄金 2021-2026 月度收益，硬编码为数组）。书中数字作为"原书示例"引用，本站实验统一用本站口径。
2. **原书存在跨章数值/费率冲突**：佣金「万分之一」vs 代码 `rate=0.001`（0.1%）；动量排名累计收益 179.96%（第 3 章）vs 153.03%（第 5 章）；印花税「千分之一」vs「0.05%」。
   → 本站**统一口径**（佣金万分之一 + 最低 5 元；印花税按 2023-08 后 0.05% 卖出单边；样本区间逐章声明），并在章内明确"**本站口径**"与"原书示例"的分界。
3. **不搬运受限内容**。原书正文 CC BY-NC-SA 4.0：本站为**自主重写的教材级讲义**（自有例子、自有图、自有习题），每章参考资料注明"结构参考 xingwudao《人人都是量化交易员》，内容为自主编写"，不整段翻译搬运。

## 10. 行情数据的工程方案（关键决策）

本站 Pyodide **无网络**、不带 yfinance/akshare，原书"下载真实 ETF 数据"的代码无法运行。方案：

**所有行情由一段「锚点 + 布朗桥」的合成价格生成器产生**，写在每节 `setupCode` / demo 开头，保证：
- **完全可复现**（`np.random.default_rng(seed)`，无随机漂移）；
- **锚点精确**（2021 初 4.00 → 2021 高点 → 2022-2023 深跌 → 2024 反弹 → 2025 末回到起点附近），因此"五年白干、波动剧烈、最大回撤 30-50%"的叙事与真实沪深 300 同构；
- **不引用任何真实行情数字**，避免把合成数据误当事实。

```python
import numpy as np, pandas as pd

ANCHORS = [(0, 4.00), (40, 4.36), (250, 3.52), (420, 2.72), (520, 3.06),
           (700, 2.94), (900, 3.32), (1010, 3.98), (1100, 3.58), (1299, 3.93)]

def make_prices(n=1300, seed=11, vol=0.0072, start='2021-01-04', anchors=ANCHORS):
    """锚点对数价格 + 布朗桥：端点与拐点精确，噪声可控，完全可复现"""
    rng = np.random.default_rng(seed)
    idx = [i for i, _ in anchors]
    lp = np.log([p for _, p in anchors])
    base = np.interp(np.arange(n), idx, lp)
    w = rng.normal(0, 1, n); w[0] = 0.0
    walk = np.cumsum(w); t = np.arange(n) / (n - 1)
    bridge = walk - t * walk[-1]
    return pd.DataFrame({'close': np.exp(base + vol * bridge)},
                        index=pd.bdate_range(start, periods=n))
```

三只"标的"用不同 seed + 不同 vol 生成（沪深300 / 纳指100 / 黄金），并写进同一节 `setupCode`，后续章节复用同一组参数，保证跨章数字一致。

- c3-c10：同一生成器扩展到 3 只与 25 只标的，供权重/相关性/IC 使用。
