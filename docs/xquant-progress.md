## 三、关键技术决策

### 1. 离线可跑的合成行情（全课程唯一数据源）

本站 Pyodide **无网络、不带 yfinance/akshare**。方案：`market.ts` 里的「锚点 + 布朗桥」生成器。

- **A（沪深300替代）**：与 c2 逐位一致，累计 +0.75%、波动 11.01%、回撤 −37.23%
- **B（纳指100替代）**：对 A 加 0.65 beta + 独立噪声，累计 +105.00%
- **C（黄金替代）**：对 A 加 0.15 beta，累计 +28.33%
- 相关性 AB 0.504 / AC 0.246 / BC 0.101（**刻意设计成"偏高但不同步"**，避免分散化变成免费的午餐）

固定 seed、端点精确、结果可复现。所有正文数字都是这条生成器的实测输出。

### 2. 口径统一（这是本次最大的工程收获）

协作过程中发现并修复了一处**跨章口径漂移**：

- **问题**：c5 自写的 `sim()` 在再平衡日 `continue`（不吃当日收益），而 `market.ts` 的 `simulate()` 先换权重再吃收益。freq=5 时两者差 **11.92pp**（41.12% vs 29.20%），因为 5 天频率下跳过了 20% 的交易日。
- **修复**：把 c5 的 4 个 demo 函数与全部正文数字、习题 blanks/tests 统一到 `market.ts` 口径（替换 108+58 处），并同步修正 c6/c10 中引用 c5 的 33 处数字。
- **连带修正**：止损结论从「有效改善（+45.11%）」调整为「轻微改善（+41.93% vs 41.69%，仅 +0.24pp）」，并重写了对应的叙事——**这个调整让结论更诚实**：同一条规则换参照点差 47.6pp，而换对参照点只赚 0.24pp，恰恰印证「结构选择的杠杆远大于参数细节」。

### 3. 主动纠正原书中与实测不符的结论

作者在实测中发现三处原书结论在本站数据上不成立，**没有编造数字去迎合**，而是把负面结果做成教学点：

| 原书结论 | 本站实测 | 处理 |
| --- | --- | --- |
| 第 8 章「恶化段与高波动段高度吻合」 | 三档命中率 25-28%，基线 26%，**无区分度** | 改为「市场状态是要检验的假设」，并补上真正有区分度的变量：63 日趋势（下跌档命中率 83%） |
| 第 8 章「波动率过滤能降 30% 回撤」 | 最大改善 17.3%，达不到门槛 | 改为「波动过滤失败、趋势过滤成功但参数是尖峰」，并在 l2/l3 互相呼应 |
| 第 7 章「取整偏差让你亏钱」 | 1 万+整手反而多赚 0.91pp（恰好少配了最差资产） | 改为「偏差方向随机 → 带来不确定性，而非亏损」 |

### 4. 8 个原创交互图（43 节全部有图）

`XQuantDiagrams.tsx`（1937 行）：`SpecFourDemo` / `DoJudgeDemo` / `ParamSawDemo` / `IsoosDemo` / `CostStepsDemo` / `ExecSlipDemo` / `Monitor3Demo` / `IcWaveDemo`。
数据全部内联写死（无 fetch、无随机），8 项交互实测通过，390px/768px 视口无横向溢出。
