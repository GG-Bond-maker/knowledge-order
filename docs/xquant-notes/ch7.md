# 第 7 章 从理想到现实：执行交易

- 原页面 URL：https://xingwudao.github.io/xquant-beginner/book/q7-execution

## 1. 章级主线（一句话 + 问题链）

一句话：把"权重 → 订单 → 成交"整条链做成可重复规则，用执行报告量出理想与现实的差距。

问题链：35% 是多少股（取整偏差）→ 按什么价成交（成交价压力测试 + 成本层叠）→ 回测与模拟交易差多少（Alpaca 模拟盘）→ 执行对不对（逐笔对账）。落点：回测收益减去预估执行落差，才是合理预期。

## 2. 节级目录（逐节）

**7.1 35% 是多少股？**
核心问题：小数权重翻译成整数股，误差有多大？
- 10 万元 A 股：沪深300ETF 8100 股（实际 34.6%，偏差 −0.41%）、纳指100ETF 14500 股（24.9%，−0.06%）、黄金ETF 4900 股（39.4%，−0.60%）；投入 ¥98,923，剩余 ¥1,077（1.08%）。
- 同样 10 万美股：SPY 59 股（35.0%）、QQQ 48 股（24.6%，−0.41%）、GLD 134 股（40.0%）；现金残余 $416.52（0.42%）。
- 资金越小偏差越大：A 股 1 万元偏差 7.8%、10 万元 0.6%；美股 1 万美元 5.3%、10 万美元 0.4%；A 股 1 万账户 9.6% 资金闲置。
- 结论：取整偏差是系统性的，现金残余是隐形损失；金额必须用 Decimal 而非 float。

**7.2 价格变了怎么办？**
核心问题：不同成交价假设加三层成本，能把收益差出多少？
- 五种 `FillPriceMode`（184~185 笔）：收盘 83.22%/夏普 1.15；中间价 85.62%/1.18；次日开盘 80.00%/1.12；次日最高 81.02%/1.14；次日最低 76.58%/1.08%。
- 最好与最差差 4.45%；次日最低比收盘少 6.64%、次日开盘少 3.22%、次日最高少 2.20%。
- 成本层叠（次日开盘）：无成本 82.44%/1.15 → +佣金万一 80.92%/1.13 → +印花税 80.00%/1.12 → +滑点 76.72%/1.09。
- 侵蚀合计 5.72%（佣金 1.52 + 印花税 0.92 + 滑点 3.28），184 笔持续累积。
- 结论：收盘价假设最乐观，成本每笔都收，这是低频优于高频的原因。

**7.3 回测和模拟交易，差距有多大？**
核心问题：换成真实接口后落差还剩多少？
- A 段 YFinance + SimBroker：SPY/QQQ/GLD 自 2021-01-01，累计 118.59%，184 笔。
- B-1 换 Alpaca IEX 数据源：112.66%，187 笔，数据源差异 5.93%。
- B-2 `LiveBroker(paper=True)`：已有 GLD 83 / QQQ 41 / SPY 51 股，仅卖 1 股 QQQ；休市时状态 accepted。
- 执行落差三来源：成交价偏差、交易成本、市场冲击；Engine 与 Strategy 一行未改。
- 结论：连数据供应商都改变结论；落差无法消除，只能监控其是否突然变贵。

**7.4 怎么知道执行得对不对？**
核心问题：整体差 6% 太粗，哪笔最贵？
- 194 笔匹配 177 笔，仅回测有 7 笔、仅模拟有 10 笔；平均滑点 +1.6199%，手续费差异 −$17.33。
- 最贵一笔：2021-02-02 SPY 买入，$356.17 vs $381.39，滑点 +7.08%。
- 分布：中位 +0.973%、最小 −0.112%、最大 +7.082%；滑点 >0.5% 的 99 笔（56%）。
- 结论：均值无害、尾部致命，必须看直方图与分标的箱线图。

**7.5 总结**：五项清单——取整偏差、成交价敏感性、交易成本、执行落差、执行质量。

## 3. 关键概念与公式

| 中文 | 英文 | 一句话 |
| --- | --- | --- |
| 取整偏差 / 现金残余 | Rounding Deviation / Cash Residual | 整手约束造成的偏离 / 闲置零头 |
| 最小交易单位 | Lot Size | A 股 100 股、美股 1 股 |
| 成交价模式 | Fill Price Mode | 假设在哪个价成交 |
| 执行不确定性 | Execution Uncertainty | 最好与最差成交价的带宽 |
| 滑点 | Slippage | 预期价与成交价之差 |
| 执行落差 | Implementation Shortfall | 决策价到成交价的全链路损耗 |
| 模拟交易 | Paper Trading | 走真实撮合但不动真钱 |

公式：实际权重 = 取整股数 × 价格 / 总资金，偏差 = 实际 − 目标；侵蚀 = 82.44% − 76.72% = 5.72%；滑点率 =（成交价 − 回测价）/ 回测价，最贵一笔 (381.39 − 356.17)/356.17 ≈ 7.08%。费率口径原文不一致：7.2 正文写"A 股卖出收千分之一"，实验段写"卖出 0.05%、折算双边约万六"；本书按后者建模，改写时应统一并注明。

## 4. 动手实验与代码

实验 1 订单生成：10 万本金空仓，A 股 `lot_size=100` vs 美股 `lot_size=1`，再扫 1/5/10/50/100 万。用 `generate_orders()` + `Decimal`；输出订单表、双市场对比、偏差与现金残余柱状图。

实验 2 成交价与成本：五种 `FillPriceMode` 各跑一次；`PercentageFee(rate=Decimal("0.0006"), min_fee=Decimal("5"))`；成本四层叠加。用 `YFinanceDownloader`、`RebalanceFrequencyRule(interval_days=21)`、`StopLossRule(threshold=0.10)`；输出净值图 + 橙色 `fill_between` 带宽、侵蚀折线。

实验 3 Alpaca 模拟：A 段 SimBroker 基准、B-1 段 `AlpacaMarketDataProvider(feed="iex")` + `Engine.setup()/step()`、B-2 段 `AlpacaClient` 读持仓 + `LiveBroker(paper=True)` 下单并等 3 秒查成交。API key 三重防线：环境变量、try/except 兜底、验收断言不含硬编码；无账号回退 `SimBroker(fill_price_mode=NEXT_OPEN)`。

实验 4 执行报告：用 `ExecutionReport` 接收 `result_sim.trades` 与 `result_live.trades`；输出前 20 笔对账表、汇总、最贵一笔、滑点直方图（30 bins）与分标的箱线图。
