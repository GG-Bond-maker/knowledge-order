## 1. 章级主线（一句话 + 问题链）

一句话：用"监控 → 诊断 → 迭代"三步 SOP，把"盯着净值焦虑"换成"用数据做决策"。

## 2. 节级目录（逐节）

**8.1 策略是不是坏了？**
核心问题：本月亏 5% 是正常波动还是策略坏了？
- 基准回测（2021 起，风险平价 + 21 天再平衡 + 10% 止损）：累计 86.45%、年化 12.50%、最大回撤 −16.62%、简化夏普 1.17、184 笔。
- 三指标：滚动夏普、滚动回撤、相对沪深 300；`roll_window=63` ≈ 3 个月交易日。
- 告警四要素：滚动夏普 <0 且持续 ≥20 交易日；每月例行 + 恶化即触发；`sharpe_threshold=0.0, min_days=20`；逐段打印起止/天数/均值。
- 检出 6 段恶化，2022 年占 4 段：02-07~04-29（58 天，−1.78）、05-05~08-10（68 天，−2.25）、08-29~09-30（23 天，−1.13）、10-10~12-01（39 天，−1.02）；另有 2023-10-18~11-14（20 天，−0.84）、2023-12-05~2024-01-03（21 天，−0.91）。
- 结论：三指标同时恶化才是危险区；发现异常不等于知道原因。

**8.2 问题出在哪？**
核心问题：恶化来自执行、市场状态还是策略设计？
- 诊断 1 执行：理想回测 92.13% vs 模拟 83.54%，累计落差 8.59%，每年约 1.72%；63 日滚动落差平稳（变化标准差 <0.5%）→ 排除执行。
- 诊断 2 市场：高波动 260 天 −1.44%/夏普 −0.08；正常 940 天 16.62%/1.80；低波动 36 天 34.72%/6.32；高波动段与恶化段高度吻合（判据重叠 ≥70%）。
- 诊断 3 参数：前后两半各测 10/15/21/42/63 天，前半段年化 1.91%~5.34%、夏普 0.25~0.65（63 天最优）；后半段 23.13%~25.78%、1.87~2.17（10 天最优）→ 排序反转。
- 结论：不是 bug 也不是过拟合，而是对高波动状态无应对方案。口诀：先排执行（外）、再查市场（中）、最后看策略（内）。

**8.3 怎么改？**
核心问题：怎样用对照实验而非直觉来改策略？
- 迭代 1（再平衡频率，假设"缩短频率能改善高波动期"）：6 种频率全时段夏普 1.17~1.39，但高波动段最好是 63 天（0.84），21 天基准 −0.08 → 假设被推翻。
- 迭代 2（波动率过滤，标准为回撤改善 ≥30% 且夏普 ≥1.0）：无过滤 −16.62%/1.17；>10% 为 −8.70%/1.18（改善 47.6%）；>15% 为 −9.62%/1.43（42.1%）；>20% 为 −12.43%/1.28（25.2%）→ 假设被确认。
- 代价：年化 12.50% → 6.57%，用 5.93% 收益换 48% 回撤改善。
- 结论：改"多久行动"无效，改"行动内容"才有效；推翻假设也是收获。

**8.4–8.5 总结**：监控/诊断/迭代三行 SOP（好信号 vs 坏信号）；核心认知 9 条；拓展阅读给出耐心、纪律、记录三条软纪律。

## 3. 关键概念与公式

| 中文 | 英文 | 一句话 |
| --- | --- | --- |
| 滚动夏普 | Rolling Sharpe | 最近 63 日的风险调整收益 |
| 滚动回撤 | Rolling Drawdown | 从近期高点的跌幅 |
| 相对基准表现 | Relative Performance | 同期跑赢/跑输沪深 300 |
| 市场状态 | Market Regime | 高波动 / 正常 / 低波动 |
| 诊断三问 | Three-step Diagnosis | 执行 → 市场 → 策略 |
| 假设驱动迭代 | Hypothesis-driven Iteration | 先定假设与标准再实验 |
| 迭代记录 | Experiment Log | 假设/标准/结果/结论留痕 |

公式与阈值：滚动窗口 63 ≈ 21 交易日 × 3；执行落差 8.59% / 5 年 ≈ 1.72%/年；回撤改善 = (16.62 − 8.70)/16.62 ≈ 47.6%；参数稳定性用 `scipy.stats.kendalltau`，tau ≥ 0.7 视为排序稳定（取值 −1~1）；告警为滚动夏普 <0 且持续 ≥20 交易日。简化夏普公式原文未给。

## 4. 动手实验与代码

实验 1 监控仪表盘：`StrategyMonitor(result_base, benchmark="510300.SS", roll_window=63)`；输出四行子图（净值 / 滚动夏普含 0 与 1 参考线 / 回撤 / 相对基准），红色填充异常区，遍历 `monitor.bad_periods` 打印明细。基准用 `SimBroker` + 风险平价 + `RebalanceFrequencyRule(interval_days=21)` + `StopLossRule(threshold=0.10)`。

实验 2 诊断三问：理想回测（收盘价 + 佣金）对比模拟交易（次日开盘 + 佣金 + 千一滑点），算 63 日滚动落差；`MarketStateDetector(result_base)` 产出 `high_vol_mask`、`market_vol`、`HIGH_VOL_LINE` 并分状态统计；再用 `scipy.stats.kendalltau` 比较前后两半 5 种频率的夏普排序。

实验 3 假设驱动迭代：`Strategy(hypothesis=..., objectives=...)` 把假设挂在策略上；迭代 1 测 6 种频率并用 `high_vol_mask` 筛高波动段；迭代 2 用 `VolFilteredOptimizer` 包装 `RiskParityOptimizer`（高波动权重 ×0.5），`best_label = argmax(dd_improvement)`；最后 `ExperimentLog(name="第 8 章迭代实验")` + `log.add()` + `to_dataframe()`。

## 8. 建议补充的知识点

1. 统计过程控制与控制图：给滚动夏普配 3σ 控制限与 CUSUM 漂移检测。Montgomery, *Introduction to Statistical Quality Control*。
2. 市场状态的严谨识别：HMM / Markov 切换模型替代波动率分位规则。Hamilton (1989)。
3. 策略衰减的统计检验：前后两段夏普差做 bootstrap 或 Jobson-Korkie 检验，而非只看 Kendall tau。Jobson & Korkie (1981)。
4. 序贯检验与早停：多次查看抬高假阳性，用 alpha-spending 控制。Jennison & Turnbull。
5. 回撤的宽度与修复周期（水下曲线），本章只报深度。
