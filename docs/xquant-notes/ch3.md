# 第 3 章 决定各买多少：3 种分法实测

- 原页面 URL：https://xingwudao.github.io/xquant-beginner/book/q3-how-much

## 1. 章级主线

一句话：同样三只 ETF、同一段历史，只换「钱怎么分」，累计收益就差出一倍以上。

问题链：第 2 章定好标的池（沪深 300、纳指 100、黄金）→ 每只买多少 → 平均分够不够好 → 组合被高波动资产主导，「平均分钱≠平均分影响力」→ 波动大的少买、小的多买（风险平价）→ 但它不看方向 → 改按涨势排名分钱（动量排名）→ 能否压成一个数字（夏普）→ 夏普有硬伤，需系统评估（第 5 章）。

## 2. 节级目录

### 3.1 各买三分之一
问题：不做任何判断、三等分，效果如何？
- 10 万元三等分，每只约 33,333 元；组合是一起分钱的标的集合，不是候选名单。
- 组合累计 80.75%、波动 11.73%、回撤 -16.79%；单只黄金 188.54% 更高，只看收益会误判。
- 组合波动率低于三只成分各自单独持有（15.83%–22.66%），分散压低了颠簸。
- 纳指 100 只花 1/3 的钱却主导组合涨跌，这是全章转折点；并串起目标权重→持仓→实际权重→再平衡。

### 3.2 波动大的少买
问题：按波动率倒数分配（简化风险平价），能否让拉扯力度更均匀？
- 权重由三等分变为 45.5%/43.3%/11.2%；10 万元下沪深 300 增至 45,510 元、黄金降至 11,239 元。
- 累计 80.75%→99.67%，波动 11.73%→10.81%，回撤 -16.79%→-12.26%。
- 表 3-3 用 20 日滚动波动率、表 3-2 用全期年化波动率，两个口径不可直接对照。
- 局限：只管颠簸，不管方向。

### 3.3 涨得好的多买
问题：改成涨得好的多买、正在跌的不买，会怎样？
- 以 ram = 动量÷波动率 打分，避免高波动标的的动量天然偏大。
- 样本末日权重 0%/0%/100%：两只动量为负被过滤，钱集中到唯一上涨的黄金。
- 累计 179.96%、波动 15.54%、回撤 -15.77%，转为高收益高波动。
- 权重图出现空白：三只动量同为负时，该方法的决策是「都别买」。

### 3.4 回头看
问题：三次实验在方法论上做了什么？
- 这叫权重分配方法对比：数据、标的池、引擎、频率全固定，只切换一个变量。
- 分工：信号答「买不买」，权重方法答「买百分之几」，规则答「何时动手」。

### 3.5 夏普比率
问题：收益与波动都不同的方案，能否压成一个可比数字？
- 标准定义＝（年化收益−无风险收益）÷年化波动；本章为讲清关系暂用简化口径：年化收益÷年化波动。
- 三方案年化收益 11.96%/13.97%/20.80%，简化夏普 1.08/1.35/1.42。
- 局限：把上涨与下跌波动一视同仁；只反映特定区间；波动为 0 时失效（现金会被算出无穷大）。

### 3.6 本章总结
问题：沉淀了哪些可迁移认知？
- 平均分钱≠平均分影响力；波动小＝低点不慌；按波动调整更稳；只换权重方法结果就不同；夏普能对比但不能只看它。
- 带走的问题：何时调整持仓（第 4 章）、样本期胜出能否复制（第 5 章）。

## 3. 关键概念与公式

| 中英对照 | 本章口径 |
| --- | --- |
| 权重 Weight／权重分配方法 | 分到总资金的比例／按什么逻辑分 |
| 组合 Portfolio／持仓 Position | 一起分钱的标的集合／实际持有份额 |
| 目标权重／实际权重 | 理想比例／按市值反算比例 |
| 再平衡 Rebalancing | 定期把实际权重拉回目标 |
| 等权／风险平价 Risk Parity | 同权重／按波动率倒数分配 |
| 动量 Momentum／RAM | 过去 N 天涨跌趋势／动量÷波动率 |
| 简化夏普 | 年化收益÷年化波动 |

- 等权 $w_i=1/N$，$N=3$ 时 33.3%；校验 $\sum w_i=1\pm10^{-6}$。
- 风险平价 $w_i=\dfrac{1/\sigma_i}{\sum_j 1/\sigma_j}$（原文只写「波动率倒数」，未给此式）。
- $\text{ram}_i=\text{mom}_i/\text{vol}_i$（原文唯一明写的构造式；动量算法原文未给，实验取 20 日）。
- 金额 $=100{,}000\times w_i$；排序型校验：活跃权重和 $=1.0$。

## 4. 动手实验与代码

实验 1 等权：三只 ETF 取交易日索引交集对齐；`EqualWeightOptimizer` 出权重，`Threshold(column="close", threshold=0, relationship="gt")` 出信号，`RebalanceFrequencyRule(interval_days=10)` 再平衡，`Engine`＋`SimBroker` 跑 2021-01-01 起（`YFinanceDownloader`/`LocalMarketDataProvider`、`StaticUniverse`、`510300.SS`/`513100.SS`/`518880.SS`）。输出权重＋10 万元换算、4×3 指标表、净值图（3 灰线＋1 蓝粗线，从 100 起）。

实验 2 风险平价：信号注册 `required_indicators={"vol":(RollingVolatility(),{"column":"close","period":20})}`，`RiskParityOptimizer(volatility_col="vol")` 读该列。输出权重对比表、指标表、净值图、权重堆叠面积图；验收加 `assert rp_w.nunique()>1` 防退化为等权。

实验 3 动量排名：三指标链 mom（`Momentum`,20 日）→vol（`RollingVolatility`,20 日）→ram（`Ratio`），顺序不可错；`TopNRankingOptimizer(score_col="ram", n=3, filter_negative=True)`。输出三方法权重表、指标表、三条净值线、面积图（负动量处留空白）。
