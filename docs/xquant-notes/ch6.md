# 第 6 章 别高兴太早：防止过拟合

- 原页面 URL：https://xingwudao.github.io/xquant-beginner/book/q6-avoid-overfitting

## 1. 章级主线（一句话 + 问题链）

一句话：用四个可复用检查工具拆开"漂亮回测"，把"疑"从感觉变成流程。

问题链：样本内冠军样本外还灵吗（IS/OOS）→ 只切一次够吗（Walk-forward）→ 换种切法结论一致吗（交叉验证）→ 会不会是规则太多（规则负担）→ 沉淀成检查清单。

## 2. 节级目录（逐节）

**6.1 能不能找到收益最好的参数？**
核心问题：490 个组合选出的样本内冠军，样本外还灵吗？
- 参数：动量窗口 5 × 波动率窗口 5 × 再平衡频率 4 × 止损有/无，约束后 490 组（70 + 420）。
- Top20 简化夏普：样本内均值 1.22（1.15~1.39），样本外 0.20（−0.09~0.50），平均衰减 −1.02。
- 全 490 组：IS/OOS 相关仅 0.04，样本外更差比例 100%，衰减均值 −0.82、中位数 −0.88。
- 结论：样本内成绩不算数，优化后必须在新数据上验证。

**6.2 市场在变，参数也该跟着变吧？**
核心问题：定期重选参数是否比死守一组更稳？
- 训练窗 2Y、验证窗 6M、共 15 折，起止日与步长全锁死。
- Rolling：样本外夏普 0.14、衰减 −36.2%、7/15 种参数；Anchored：0.13、−23.5%、5/15。
- Anchored 有 7 折同选（20,15,5），再平衡频率 15 折全为 5。
- 结论：参数稳定性比参数最优更重要。

**6.3 一条路径够可靠吗？**
核心问题：换一种数据切法，结论还一样吗？
- 5 折时序交叉验证（expanding），禁用随机 KFold。
- 逐折样本外夏普 0.69/0.44/0.28/1.56/1.79，汇总 0.95 ± 0.68，唯一组合 4/5。
- Fold3、Fold4 的 (20,15,5) 与 Anchored 最频繁参数一致：切法换了结论没变。
- 结论：交叉验证给的是"把握有多大"，不是"最优参数"。

**6.4 规则越多回测越好，是好事吗？**
核心问题：加规则换来的样本内提升，样本外兑现吗？
- 4A 组合数 1→3→18→57→183→825；样本内 0.94→1.06→1.11→1.33；样本外 0.52→−0.07→0.36→0.15。
- Layer 3/4/5 数字完全相同（1.33 / 0.15 / −1.18）：约束链锁死了新增旋钮。
- 4B 自由度 1→2→3→4→6：样本内 1.07→1.56，样本外 −0.17→0.01→0.01→0.50→−0.07，拐点在 D→E。
- 结论：规则负担；能用 2 个参数解决，不要用 6 个。

**6.5–6.6 总结**：五项清单——样本外、Walk-forward、交叉验证、规则负担、参数敏感性，各配好坏信号。

## 3. 关键概念与公式

| 中文 | 英文 | 一句话 |
| --- | --- | --- |
| 样本内 / 样本外 | IS / OOS | 调参的卷子 / 没见过的卷子 |
| 过拟合 | Overfitting | 记住噪音而非规律 |
| 前推分析 | Walk-forward | 历史上模拟定期重优化 |
| 滚动式 / 锚定式 | Rolling / Anchored | 定宽滑动 / 起点固定加长 |
| 参数稳定性 | Parameter Stability | 好参数跨窗口一致 |
| 时间序列分割 | Time-Series Split | 训练集永远早于测试集 |
| 数据泄露 | Look-Ahead Bias | 让模型看到未来 |
| 规则负担 / 自由度 | Rule Burden / DoF | 规则也会过拟合 / 可调旋钮数 |

公式（取自原文）：衰减 Δ = SR_oos − SR_is，Top20 平均 0.20 − 1.22 = −1.02；变异系数 0.68 / 0.95 ≈ 0.72（原文称小于 1）；组合数 5×5×4×(1+6) = 600，约束后 490。简化夏普为书中自定义口径，公式原文未给。

## 4. 动手实验与代码

实验 1 IS/OOS：IS 2017-01-01~2020-12-31、OOS 2021-01-01~2023-01-31；`oxq.optimize.GridSearch`、`ParameterSet`、DSL 约束 `interval_days <= mom.period`；输出 Top20 表、IS-OOS 散点（y=x 虚线）、双柱图。

实验 2 Walk-forward：`oxq.optimize.WalkForward`（`train_period="2Y"`、`test_period="6M"`、`anchored`）、`deterioration()`；输出 15 折表与参数轨线图。

实验 3 交叉验证：`oxq.optimize.TimeSeriesCV(n_splits=5, expanding=True)` + `cross_validate()`；输出逐折表、双柱图 + 均值线。

实验 4 规则负担：自写 `run_layer()`；约束链 `sl < tp`、`trail >= sl`、`max_dd >= sl`；输出 4A/4B 两表两图与拐点结论。

## 8. 建议补充的知识点

1. Deflated Sharpe Ratio：回答"试 490 次后还剩多少显著性"。Bailey & López de Prado (2014), JPM。
2. 多重检验校正：Bonferroni α/N、White's Reality Check。White (2000), Econometrica。
3. 回测过拟合概率 PBO 与 CPCV。Bailey et al. (2017)。
4. Purged & Embargoed K-Fold。López de Prado (2018), AFML Ch.7。
5. 复杂度惩罚：把"2 优于 6"升级为 AIC/BIC 式惩罚项。
